## Значения статусов
- **mobile / web / оба** — дом активности.
- **live** — только в реальном времени с людьми (клуб, встреча).
- **offline** — работает без сети (сессия, SRS, чтение скачанного) [R доступность].
- **community event** — вне устройства (кафе, прогулка).

## Правило нераздувания (против «помеси»)
Активность не переносить на экран, для которого она не рождена: длинное письмо — не на телефон; ритуал перед сном — не на десктоп; групповой созвон — не в карман на ходу. Данные общие (один аккаунт, журнал событий Фаза C) — прогресс перетекает без швов.

## Один день, два устройства (учебный цикл)
Утро (mobile 12 мин: поток+контекст+речь) → день (desktop, когда есть: письмо/грамматика/диалог 20–40 мин) → вечер (mobile 3 мин: круг). Телефон строит привычку и снимает страх голоса; стол превращает привычку в мастерство.
