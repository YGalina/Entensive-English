# Exercise Redesign Matrix

Date: 2026-07-14

Purpose: redesign weak exercises without removing useful old-fashioned mechanics merely because they look old-fashioned.

## 1. "Now Make Your Own Sentence"

Current weakness: if asked too early, it tests invention, not learning.

Decision: REDESIGN.

Appropriate when:

- learner understands the item;
- has seen 3-5 natural examples;
- knows the target meaning;
- gets a semantic constraint;
- receives feedback and retries;
- later reuses it.

Required scaffold:

1. understand example;
2. notice chunk;
3. choose correct meaning;
4. complete fixed phrase;
5. substitute one slot;
6. answer bounded personal prompt;
7. retry after feedback;
8. delayed recall.

Success measure:

- target item used naturally;
- not avoided;
- reused later in changed context.

## 2. Word Floods / Rapid Word Flow

Current weakness: too easily treated as acquisition.

Decision: REDESIGN.

Appropriate when:

- framed as exposure/preview;
- linked to immediate context;
- includes audio and L1 meaning;
- not too many items for ordinary daily mode;
- followed by retrieval.

Stronger sequence:

`preview → context → recognition → productive cue → phrase use → later recycle`

Success measure:

- later recognition in context;
- productive recall for selected high-value items.

## 3. Isolated Vocabulary Lists

Current weakness: word = translation, no depth.

Decision: KEEP BUT REPOSITION.

Appropriate when:

- initial form-meaning mapping is needed;
- frequency/high utility is clear;
- paired with pronunciation and context.

Stronger sequence:

- word/chunk;
- L1 meaning;
- audio;
- short natural example;
- collocation;
- productive SRS;
- use in context.

Success measure:

- learner can retrieve from meaning and use in phrase.

## 4. Passive Film Watching

Current weakness: attention and retrieval are missing.

Decision: REDESIGN.

Appropriate when:

- content is motivating;
- tasks are light enough not to kill pleasure;
- extraction is selective.

Stronger sequence:

1. predict;
2. watch for gist;
3. watch selected scene with transcript;
4. extract 3-7 chunks;
5. shadow 1-2 lines;
6. retell;
7. discuss;
8. recycle chunks.

Success measure:

- learner can retell or use selected chunks later.

## 5. Passive Book Reading

Current weakness: reading does not automatically become speaking.

Decision: REDESIGN.

Appropriate when:

- level is not too hard;
- reading volume is high enough;
- output is attached.

Stronger sequence:

- read;
- mark 3 useful phrases;
- summarize paragraph;
- answer one personal question;
- use one phrase in writing/speech.

Success measure:

- comprehension plus oral/written reuse.

## 6. Unstructured AI Conversation

Current weakness: entertaining but instructionally static.

Decision: REPLACE for core learning; keep as optional free practice.

Stronger sequence:

- choose scenario;
- pre-load target chunks;
- set communicative goal;
- conversation with constraints;
- feedback prompt;
- self-repair;
- retry same function;
- changed scenario later.

Success measure:

- target language used;
- repair completed;
- later transfer.

## 7. Repetition Without Variation

Current weakness: memorized sequence without flexible use.

Decision: REDESIGN.

Appropriate when:

- pronunciation/prosody or initial automaticity is the target.

Stronger sequence:

`repeat → substitute → transform → personalize → use in new context`

Success measure:

- learner can alter the phrase without losing accuracy.

## 8. Shadowing Without Comprehension

Current weakness: mouth movement without language learning.

Decision: REDESIGN.

Appropriate when:

- phrase is short;
- meaning is clear;
- transcript available;
- target is rhythm/prosody.

Stronger sequence:

1. understand;
2. listen;
3. mark stress;
4. repeat after;
5. speak with;
6. speak alone;
7. record;
8. use phrase in own output.

Success measure:

- improved intelligibility/prosody and later independent use.

## 9. Grammar Quizzes Disconnected From Speech

Current weakness: recognition does not proceduralize.

Decision: REPLACE as core; keep as diagnostic/support.

Stronger sequence:

- meaning contrast;
- choose form;
- complete;
- transform;
- listen-build;
- say aloud;
- personal answer;
- unannounced later task.

Success measure:

- target grammar appears in speech, not only quiz.

## 10. Phrase Builder Showing the Answer

Current weakness: if already assembled, it trains reading, not listening/retrieval.

Decision: REDESIGN.

Stronger sequence:

1. hear full phrase;
2. hide text;
3. learner orders/chooses pieces from memory;
4. first error gives hint, not answer;
5. learner says full phrase;
6. then sees model;
7. says personal variant.

Success measure:

- reconstruction from audio and meaning.

## 11. Exercise Quality Gate

Before an exercise enters core curriculum, it must answer:

- What exact subskill does it train?
- Does it require retrieval or only recognition?
- Can learner avoid the target form?
- Is feedback specific?
- Is there retry?
- Is there delayed recall?
- Is there transfer to changed context?
- Is success observable?

If not, it is content, not training.
