# B1 to B2 Progression Architecture

Date: 2026-07-14

Goal: move uneven A2/B1/B1+ adult learners toward functional B2, then prepare a later C1 track.

## 1. Entry Assumption

The learner does not have a complete passive B2 system. She has uneven competence:

- some B2 reading islands;
- B1 listening or lower;
- A2/B1 productive vocabulary;
- grammar knowledge that collapses under time pressure;
- speaking anxiety and perfectionism.

The system must place each skill separately.

## 2. Dependency Model

```
comprehensible input
→ noticing of reusable forms
→ lexical/chunk retrieval
→ grammar frames
→ pronunciation/prosody rehearsal
→ controlled output
→ guided personal output
→ task repetition
→ interaction and repair
→ transfer to real domains
```

No stage disappears later. The programme spirals upward with harder content, less support, and more time pressure.

## 3. Stage 0: Diagnostic and Calibration

Duration: first 1-3 days.

Train: not much yet; measure and reduce fear.

Activities:

- vocabulary recognition check;
- listening gist check;
- 45-60 sec speaking sample;
- written short answer;
- confidence/freeze questions;
- native language/interface language split.

Output: profile, not one level.

Decision basis: research-supported and programme precedent.

## 4. Stage 1: Receptive Foundation with Tiny Output

Target: weak A2/B1 productive learners.

Focus:

- high-frequency vocabulary;
- chunks for everyday domains;
- listening segmentation;
- simple grammar frames;
- one-sentence output.

Activities:

- short input blocks;
- contextual translation;
- listen/repeat selected lines;
- recognition SRS;
- productive cue for stable items;
- constrained "say one sentence".

Mastery:

- understands short contexts;
- retrieves common chunks with cue;
- says 1-2 personal sentences without giving up.

## 5. Stage 2: Controlled Production

Target: B1 foundation.

Focus:

- collocations;
- phrasal verbs;
- tense/aspect contrasts;
- discourse moves for explanation;
- pronunciation in phrases.

Activities:

- grammar listen-build;
- substitution/transformation;
- phrase reconstruction;
- productive SRS;
- short retells;
- AI feedback with retry.

Mastery:

- produces target structures in controlled speech;
- repairs 1 priority error;
- repeats improved version.

## 6. Stage 3: Guided Personal Output

Target: B1 to B1+.

Focus:

- personal meaning;
- fluency with known language;
- reducing translation time;
- expanding from sentence to short turn.

Activities:

- answer personal questions with target chunks;
- 4/3/2 short retell;
- "say same idea in another way";
- mini writing;
- evening circle sentence;
- saved phrase reuse.

Mastery:

- speaks 45-90 sec on familiar topic;
- uses active chunks;
- self-corrects common errors.

## 7. Stage 4: Interaction and Complication

Target: B1+ to B2.

Focus:

- turn-taking;
- clarification;
- disagreement;
- follow-up;
- real-time retrieval.

Activities:

- role-play with goal;
- information gap;
- AI scenario with surprise;
- peer/native-speaker structured session;
- repair drills;
- same task with changed context.

Mastery:

- handles misunderstanding;
- asks follow-up questions;
- maintains conversation without freezing.

## 8. Stage 5: B2 Functional Performance

Target: functional B2.

Focus:

- connected discourse;
- explanation/argument;
- domain-specific language;
- higher accuracy while speaking.

Activities:

- film/book discussion;
- work/life scenarios;
- presentations;
- debates with preparation;
- external speaking sample;
- writing cycles.

Mastery:

- narrates, explains, argues, summarizes;
- speaks to a human or group with tolerable anxiety;
- transfers trained language to new content.

## 9. Later C1 Track

C1 is not just more B2.

It requires:

- nuanced vocabulary and register;
- abstract discourse;
- fast authentic input;
- pragmatic control;
- professional writing/speaking;
- sustained argument;
- recovery from complex interaction breakdowns.

C1 should be a later "studio" track with heavier web, human feedback, writing, domain practice, and external assessment.

## 10. Uneven Profile Handling

Example profile:

- Reading: B2
- Listening: B1
- Productive vocabulary: A2/B1
- Grammar recognition: B1
- Spontaneous speaking: A2

The programme response:

- reading input can be B2 but output tasks must start A2/B1;
- listening should use B1/B1+ material with transcript scaffolds;
- grammar should train high-frequency structures in speech, not advanced explanations;
- speaking should start with one sentence and repair strategies;
- progress screen must show separate skill bands.

## 11. Weekly Architecture

Every week should contain:

- 3-5 input blocks;
- 3 productive SRS sessions;
- 2 grammar-in-speech drills;
- 2 pronunciation/prosody loops;
- 2 short spoken outputs;
- 1 longer retell/discussion;
- 1 review of saved errors/chunks;
- optional human/peer practice when ready.

## 12. B2 Readiness Criteria

A learner is approaching B2 when she can:

- understand the gist and many details of authentic but supported material;
- retrieve common chunks without long translation pauses;
- speak for 2 minutes on familiar topics;
- narrate and explain with connectors;
- handle clarification and repair;
- write a clear short message;
- maintain practice rhythm without shame collapse.
