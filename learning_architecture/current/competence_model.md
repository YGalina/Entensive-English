# Intensive English Competence Model

Date: 2026-07-14

Principle: Intensive English must diagnose and train competences separately. A learner can be B2 in reading, B1 in listening, A2 in productive vocabulary, B1 in grammar recognition, and A2 in spontaneous speaking.

## Competence Matrix

| Competence | Observable behaviour | Progression stages | Diagnostic method | Practice types | Mastery criteria | Transfer test |
|---|---|---|---|---|---|---|
| Vocabulary breadth | understands enough words across domains | A2 core → B1 high-frequency → B2 domain range → C1 low-frequency/abstract | recognition sample + reading/listening text | contextual input, SRS, reading, listening | 85-90% comprehension in levelled text | understand a new text on same level |
| Vocabulary depth | knows meaning, register, forms, constraints | translation → example → collocation → polysemy → register | explain/use word in context | word families, examples, contrast, cloze | chooses natural use in sentence | use word in changed context |
| Productive vocabulary | retrieves words from meaning | cannot recall → cue recall → fast recall → flexible use | L1/meaning→English cue | productive SRS, oral recall, constrained answers | produces without seeing English | timed answer with target words |
| Formulaic language | uses chunks as wholes | notices phrase → repeats → retrieves → adapts | phrase completion/role task | chunk SRS, dialogue completion, substitutions | retrieves chunk under time pressure | use chunk in new scenario |
| Collocations | says natural word partnerships | word-only → common collocations → flexible choices | collocation cloze/speech sample | collocation cards, cloze, feedback | avoids major unnatural combinations | explain same idea with natural collocation |
| Phrasal verbs | understands and uses particles | recognizes → separates meanings → uses in scenario | meaning contrast and production | scenario examples, particle contrast, role-play | uses top phrasal verbs in speech | solve scenario using target verb |
| Grammar knowledge | understands form and meaning | rule recognition → form choice → meaning contrast | selected response + explanation | mini explanations, processing instruction | chooses form for meaning | identify why two forms differ |
| Grammar proceduralisation | uses grammar while speaking | slow construction → frame use → timed use → automatic | spoken transformation task | listen-build, transformations, 4/3/2, retry | uses target in speech with low pause load | unannounced speaking task |
| Listening decoding | hears word boundaries/sounds | blur → familiar words → chunks → reduced speech | dictation/segmentation | narrow listening, transcript, HVPT, shadowing | catches target forms in natural audio | new speaker, same phrase type |
| Listening comprehension | understands message | gist → details → inference → stance | audio questions + retell | graded audio, repeated listening, scene tasks | accurate gist/details without L1 subtitles | summarize new clip |
| Pronunciation | produces intelligible sounds | aware → controlled → phrase-level → automatic | recording + intelligibility check | articulatory cues, minimal pairs if needed | comprehensible to non-teacher listener | unknown listener understands |
| Prosody | uses stress, rhythm, intonation | flat/L1 rhythm → imitation → controlled phrase → discourse rhythm | shadowing recording | shadowing, choral repetition, marked scripts | speech sounds easier to follow | retell with natural chunking |
| Speaking fluency | speaks with manageable pauses | single words → sentence → short turn → connected speech | 60-120 sec sample | repeated retell, 4/3/2, role tasks | fewer long pauses, more clauses/min | repeat topic with new listener |
| Speaking accuracy | controls forms under pressure | many fossilized errors → noticed → repaired → stable | speech sample error profile | prompts, self-repair, focused retry | priority errors decline across samples | new task with same structure |
| Speaking complexity | expresses nuance | simple sentences → connectors → hypotheticals → argument | discourse sample | sentence expansion, story retell, debate | can explain reasons/conditions | handle abstract prompt |
| Interaction | manages turn-taking | answers only → asks → follows up → negotiates | role-play with interruption | info gaps, repair tasks, live practice | initiates/repairs without freezing | human/AI unpredictable scenario |
| Repair strategies | survives breakdown | freezes → asks repeat → clarifies → reformulates | breakdown simulation | repair phrase drills, role-play | uses repair phrases automatically | partner misunderstands intentionally |
| Reading | reads for meaning and language | word-by-word → gist → extensive → analytical | WPM + comprehension + recall | graded/extensive reading, annotation | speed with comprehension | new text plus oral summary |
| Writing | writes clear short messages | sentence → paragraph → genre → revision | writing sample | model, scaffold, feedback, revision | improved second draft | write to real purpose |
| Pragmatic competence | chooses socially appropriate language | literal → polite frames → register → nuance | scenario judgment | model dialogues, role-play, feedback | appropriate tone and function | handle status-sensitive scenario |
| Confidence | acts despite imperfection | avoidance → safe attempt → repeated attempts → agency | self-rating + behaviour | tiny wins, AI rehearsal, human checkpoints | tries without long delay | first attempt in new task |
| Willingness to communicate | chooses to speak | silent → prompted → voluntary → initiates | behaviour logs | safe speaking, groups, mission tasks | starts speaking opportunities | joins live/peer event |
| Study habits | returns consistently | burst/drop → small rhythm → stable routine | time log and missed-day recovery | plans, return protocol, accountability | consistent weekly hours | resumes after missed days |
| Metacognition | knows what to train next | vague level → skill profile → self-adjustment | reflection + dashboard | weekly review, goal checks | can name next bottleneck | chooses correct practice mode |

## Diagnostic Profile

A learner profile should show separate bands:

- lexical recognition;
- productive vocabulary;
- listening decoding;
- listening comprehension;
- grammar recognition;
- grammar in speech;
- pronunciation/prosody;
- fluency;
- interaction;
- confidence/WTC;
- habit stability.

## Mastery Definition

Mastery in Intensive English does not mean "I completed the lesson".

It means:

1. I can understand the item in context.
2. I can retrieve it from meaning.
3. I can say/write it in a controlled frame.
4. I can adapt it to my life.
5. I can reuse it later.
6. I can transfer it to a new context.

## Progress Reporting

Report capabilities, not vanity totals:

- "You recognized 42 new words" is a recognition metric.
- "You recalled 18 from meaning" is a productive retrieval metric.
- "You used 6 in your own speech" is a production metric.
- "You reused 3 after delay" is an active-language metric.

The learner should never be told that recognition equals speaking.
