# Разделение обучения между Mobile и Web

Дата: 2026-07-14

Принцип: распределение по платформам сначала следует из учебной задачи, и только потом из UX-удобства.

## 1. Логика платформ

Mobile - это не урезанный web.

Web - это не склад для сложных задач.

Mobile строит ритм, голос, повторение без лишнего сопротивления и возвращение после паузы.

Web строит глубину, анализ, письмо, длинное чтение, сборку грамматики и review прогресса.

## 2. Распределение активностей

| Активность | Платформа | Методическая причина | UX-причина |
|---|---|---|---|
| Daily session | обе, mobile primary | habit и input-output loop | телефон всегда рядом |
| Word flow | mobile focus, web optional | perceptual preview короткими bursts | full-screen ritual хорошо работает на телефоне |
| Context reading/listening | обе | input должен соединяться с output | на телефоне коротко, на web глубже |
| Context audio loop | mobile primary | listening repetition в малых окнах | наушники |
| Recognition SRS | mobile primary | micro retrieval | очереди по 3-5 минут |
| Productive SRS | mobile primary | meaning→speech retrieval | голос в руке |
| "Say your own" | обе | output в каждой сессии | mobile voice, web text/longer |
| Pronunciation | mobile primary | запись и повторение | интимно, удобно в наушниках |
| Shadowing | обе | mobile для повторения, web для анализа | телефон на прогулке, web с большим transcript |
| Grammar workshop | web primary; mobile micro | нужен visual comparison и deliberate construction | keyboard/space |
| Phrase builder from audio | обе | retrieval from listening | mobile short, web longer |
| Typing/motor channel | только web | keyboard motor memory | настоящая клавиатура |
| Reading books | обе | extensive reading | mobile short, web long |
| Speed reading | web primary | attention and measurement | larger screen |
| Writing | web primary; mobile 3-4 lines | revision and genre work | keyboard |
| Role-play | обе | speaking/interaction | mobile voice, web longer scenarios |
| AI conversation | обе | rehearsal | зависит от контекста |
| Speaking sample | mobile primary | natural voice recording | микрофон в руке |
| Progress map | web primary | metacognition and analysis | большой экран |
| Evening circle | mobile primary | bedtime closure | phone nearby |
| Guardians | обе | friction-point support | появляется там, где возник блок |
| Peer/native club | live + обе | interaction transfer | video stable on web; check-in mobile |
| Offline event | offline + mobile | real transfer | location/check-in |
| Payments/account | web primary | not learning | forms and policies |

## 3. Mobile Curriculum Shape

Mobile должен давать:

- Today;
- session;
- SRS;
- speak;
- listen/shadow;
- evening;
- people/check-in;
- profile controls.

Mobile должен избегать:

- длинных grammar tables;
- тяжёлого typing;
- dashboards with too much analysis;
- длинных writing tasks.

## 4. Web Curriculum Shape

Web должен давать:

- focus session;
- grammar workshop;
- writing workshop;
- reading studio;
- shadowing studio;
- vocabulary table;
- progress map;
- assessment archive;
- club rooms.

Web должен избегать:

- being only a clone of mobile;
- hiding difficult but essential work in obscure tabs.

## 5. Live and Offline Layer

Live:

- coached speaking;
- group training;
- book/film clubs;
- task events.

Offline:

- cafe conversation;
- language walk;
- local partner session.

Приложение готовит, фиксирует и возвращает материал. Оно не должно притворяться, что экран сам по себе является всей языковой средой.

## 6. Split by Cognitive Load

| Cognitive demand | Best platform |
|---|---|
| quick recall | mobile |
| voice attempt | mobile |
| pronunciation loop | mobile |
| deep comparison | web |
| writing revision | web |
| long reading | web |
| social anxiety exposure | live/mobile |
| strategic review | web |
| habit rescue | mobile |

## 7. Design Consequence

Каждый экран должен отвечать:

- в каком learning state находится ученик?
- подходит ли эта платформа под это состояние?
- какой следующий cognitive transition?

Если feature не может ответить на это, её нужно переместить, слить с другой или убрать.
