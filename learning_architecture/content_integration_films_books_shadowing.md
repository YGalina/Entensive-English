# Интеграция фильмов, книг и shadowing в учебную программу

Дата: 2026-07-13 · метки [R][P][H]. (TASK 6) Оставляем культуру, НЕ превращаем в фабрику воркшитов.
Принцип [R]: любой вход обязан заканчиваться extraction + output, иначе это пассив (экстенсивное чтение/просмотр сами по себе продукцию не дают).

## Общий конвейер (13 фаз брифа, адаптировано)
Единый шаблон, где культурная ценность материала ведёт, а язык извлекается «по пути» — не наоборот.

| Фаза | Что | Обязательна? |
|---|---|---|
| pre-task | 8–15 целевых chunks/слов из фрагмента + вопрос-крючок | да [R подготовка] |
| input | сам материал (сцена/глава/эпизод) в удовольствие | да |
| comprehension | 1 вопрос на смысл (не детали) | да [R] (гейт) |
| language extraction | подсветить встреченные целевые единицы | да |
| phrase selection | ученик сам выбирает 3–5 «своих» фраз | да [H персонализация] |
| listening work | decoding-фрагмент (редукции/связки) | если аудио |
| pronunciation work | shadowing 3–5 ключевых фраз | если аудио |
| retrieval | SRS продуктивно на выбранные единицы | да [R] |
| discussion | 1 реплика/мнение о материале | опц. |
| retelling | пересказ 1 мысли своими словами | да [R protégé/output] |
| writing | 3–4 строки (desktop) | опц. |
| real-life transfer | «где скажешь это в жизни» + план | да [H] |
| later recycling | единицы возвращаются в поток/диалог | да [R] |

## Потоки по типам контента

### Сцена из фильма (2–4 мин) [H культурный крючок]
pre: 10 chunks + «что произойдёт?» → смотрит → comprehension (мотив героя) → extraction → выбор фраз → shadowing реплики (эмоция!) → «сыграй реплику» (формат фазы 4) → SRS.
Акцент: эмоция несёт chunk; реплика героя — готовый формульный блок. НЕ разбирать всю грамматику сцены.

### Эпизод сериала [P сериальность = habit]
Как сцена, но сквозная лексика героев накапливается по эпизодам (recycling встроен); «фраза недели» из эпизода.
Акцент: возвращаемость персонажей = естественный интервальный повтор.

### Глава книги [R экстенсивное чтение + output]
pre: 8 chunks → читает главу (тап-перевод) → comprehension → выбор фраз → «скажи своё об этом» → SRS.
Акцент: obligatory output-пришивка (иначе пассив, доказано нулём PVLT).

### Короткий рассказ [P]
Целиком за сессию: read → extraction → retelling (1 мысль) → 1 продуктивная фраза.
Акцент: завершённость = мотивация; целостный нарратив как модель дискурса.

### Подкаст [R listening]
pre: 12 chunks → слушает → decoding-фрагмент → shadowing → «объясни мысль» → SRS.
Акцент: слух — ведущий навык; редукции/связки; тап=перевод по запросу.

### Реальный разговор (клуб/встреча) [R interaction] — вершина
pre: 3 фразы-разогрева → участие → post: доска фраз с общей встречи → в словарь → ноутинг «где застряла».
Акцент: непредсказуемость = тест переноса (T6); фидбэк ПОСЛЕ, не во время (аффект).

## Правило против «фабрики воркшитов»
- **Максимум ОДИН obligatory output на единицу контента** (не 12 заданий к главе).
- **Ученик выбирает свои фразы** — не мы навязываем список (персонализация = кодирование [H]).
- **Культурная/смысловая ценность первична:** сначала «хочу досмотреть/дочитать», потом язык. Если материал скучен — меняем материал, а не добавляем упражнения.
- **YouTube-импорт [F Галина]:** «видео, которое ты и так хочешь посмотреть — сильнейший источник слов»; конвейер тот же, но материал выбирает ученик.
