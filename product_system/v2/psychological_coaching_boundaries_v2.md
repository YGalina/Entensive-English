# Психологический слой и границы коучинга · v2

Дата: 2026-07-13 · (PHASE 9) Поддержка обучения БЕЗ имитации психотерапии.

## Различаем состояния (и что продукт с ними делает)
| Состояние | Продукт МОЖЕТ | Продукт НЕ должен |
|---|---|---|
| Нормальная языковая тревога | нормализация, градуированная экспозиция, низкие ставки | «вылечить тревожность» |
| Избегание | implementation intentions, «вернуться с 5 мин» | стыдить |
| Перфекционизм | «достаточно хорошо», ретрай без штрафа | требовать идеала |
| Страх негативной оценки | приватность записи, ноль красного | публичный рейтинг ошибок |
| Срыв привычки | recovery-режим, мягкий зов | «стрик сгорел» |
| Низкая самоэффективность | «что я теперь могу», доказательства | пустая похвала |
| **Клинически значимая тревога/mental-health** | **дать мягкий disclaimer + ссылку на помощь; НЕ вести** | диагностировать/лечить/обещать |

## Продукт МОЖЕТ (в границах)
нормализация · саморегуляция · градуированная экспозиция к речи (текст→шёпот→вслух) · низкие ставки · автономия · восстановление после пропуска · не-стыдящая ОС · implementation intentions · рефлексия · подотчётность · коучинг (не-клинический).

## Продукт НЕ ДОЛЖЕН (красные линии — из [R] + этика)
диагностировать · лечить расстройства · проводить терапию · гарантировать устранение тревоги · заменять психолога. (Наука: конкретное устойчивое вмешательство по тревожности — [U]; «преодолей тревожность» — за пределами данных.)

## Аудит терминологии
| Термин | Рекомендация | Почему |
|---|---|---|
| **guardian / страж** | **keep как метафора** (user-facing), но НЕ клиническая рамка | тёплая, деперсонифицирует барьер; не диагноз |
| **affect gate / аффект-гейт** | **internal only** | инженерный термин, не показывать |
| **freeze / замирание** | keep (user-facing) | точное переживание, узнаваемо |
| **inner part / часть меня (IFS)** | **use carefully / внутренне** | IFS — терапевт. модель; как метафора «часть, которая боится» — ок, но НЕ заявлять IFS-терапию |
| **psychological barrier / барьер** | keep (нейтрально) | общеупотребимо |
| «работа с частями» как метод | **переформулировать**: «замечаем чувство, даём место, делаем шаг» — БЕЗ терапевтического бренда | не имитировать терапию |

## Границы безопасности и эскалация
- Если пользователь выражает серьёзный дистресс/mental-health → мягкое сообщение: «это важнее английского; вот куда можно обратиться за поддержкой» + ссылка на ресурсы; НЕ продолжать «психо-упражнение».
- Никаких клинических опросников/скринингов.
- Тексты стражей/практик — на редактуру психолога Галины (уже в плане), с этим disclaimer-каркасом.
- Формат стражей — [B гипотеза], не доказанный: валидировать, что помогает продолжению, не вредит.

## Поправка к v1
v1 подавал стражи/аффект-гейт местами как доказанную «поведенческую систему» и «психологическую опору» — переклассифицировано: **феномен тревоги [A/R] реален; НАШ формат поддержки [B гипотеза]; терапией не является [этическая граница].** «Аффект — гейт» как принцип верен (тревога блокирует извлечение), но не как обещание лечения.
