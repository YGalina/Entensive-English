# Учебный план B1→B2 · v2 (blueprint)

Дата: 2026-07-13 · (PHASE 3) Реальная программа, не список тем. Для неровного A2–B1/B1 → B2. Опора: CEFR/companion volume, Cambridge GLH [P], Nation strands [P], gap/science [R].
Красная линия: не обещать B2 к фикс. сроку. Продукт делает ОБА: строит недостающую компетенцию по всем навыкам + конвертирует в самостоятельное употребление. Не сводить ни к «активации речи», ни к «чанкам», ни к «психологии».

## Диагноз ЦА (общий)
**High-knowledge / low-access** (Codex 18 корроборирует): декларативное знание высокое, процедурный доступ низкий, аффект высокий. → программа грузит НЕ новое знание правил, а извлечение-в-речь + недостающие слои (продуктивный словарь, коллокации, фразовые, слух беглой речи, произношение) + процедурализацию имеющейся грамматики.

## Стадии (по функции; вход/цель/пререквизиты/содержание/оценка/выход)

### S0 · A2→B1 вход
- **Вход:** реагирует, комбинирует заученное; продуктивный словарь мал.
- **Цель:** бытовые/рабочие функции реактивно; первые коллокации в продукции.
- **Пререкв.:** ~1.5–2k рецептив.
- **Содержание:** высокочастотное ядро; present/past, базовые вопросы; коллокации быта.
- **Слух:** цитатные формы→простая связная речь. **Произн.:** проблемные сегменты RU-L1.
- **Речь-функции:** представиться, спросить/ответить, простое мнение.
- **Чтение/письмо:** короткие тексты; 3–4 строки.
- **Задачи:** микро-диалоги; статус дня.
- **Оценка формативная:** продуктивный ретрив; выход — реактивная бытовая речь.

### S1 · B1 ядро
- **Вход:** справляется с бытом реактивно; грамматика узнаётся, ломается в речи.
- **Цель:** связный короткий монолог; инициирует простой обмен.
- **Содержание:** 2–3k продуктив; present perfect, conditionals-1/2, reported speech (узнавание→употребление); коллокации работа/быт; частотные фразовые.
- **Слух:** редукции/связки (decoding). **Произн.:** разборчивость+первая просодия.
- **Речь:** нарратив о себе, объяснение, несогласие вежливо.
- **Письмо:** сообщение/письмо с опорами.
- **Задачи:** повтор задачи с вариацией (процедурализация старт).
- **Оценка:** 2-мин sample; выход — связный монолог + инициатива.

### S2 · B1→B2 мост (ключевая стадия)
- **Вход:** знает много, не достаёт быстро; freeze под давлением.
- **Цель:** **процедурализация (T4) + беглость (T5)**; chunks в активе; управляет диалогом.
- **Содержание:** формульные фреймы дискурса; фразовые в активе; conditionals-3, passive, relative; продвинутые коллокации.
- **Слух:** беглая аутентичная речь. **Произн.:** просодия/интонация под смысл.
- **Речь:** аргумент, нарратив абзацем; repair-стратегии.
- **Письмо:** структурированный текст жанра.
- **Задачи:** 4/3/2 (на СФОРМИРОВАННЫХ фреймах); диалог с персонажем; клуб.
- **Оценка:** EIT-подобное (грамматика под временем) + speaking sample CALF; выход — беглость без обвала точности.

### S3 · B2 ядро
- **Вход:** говорит, но простое/или сложное-с-ошибками.
- **Цель:** сложность+точность без размена; чинит сбои; нарратив/аргумент.
- **Содержание:** нюанс, регистр, идиоматика; тонкая грамматика (aspect, hypotheticals).
- **Речь/взаимод.:** ведёт обмен, перебивает вежливо, подводит итог.
- **Оценка:** интегрированный срез; выход — B2-функции в непредсказуемом.

### S4 · B2→C1 (позже)
- нюанс/спонтанность/прагматика на новом; перенос T6.

## Режимы нагрузки (ориентиры [H], не РКИ)
Sustainable 3.5–5ч/нед · Accelerated 7–10 · Bootcamp 12–18 (куратор) · Maintenance 1.5–2.5 · Recovery «вернуться с 5 мин». Cambridge GLH ориентир: B1→B2 ≈200ч. Скорость зависит от регулярности и доли output.

## Неровный профиль (пример: reading B2·listening B1·prod.vocab A2·grammar-recog B1·speaking A2)
1. Диагностика по дорожкам (не один ярлык).
2. План ведёт узкое место: грузим продуктивный словарь+коллокации+процедурализацию+беглость (A2-речь), НЕ чтение (уже B2).
3. Материал берём из верхней дорожки (тексты B2 по интересу) — извлечение делаем на нижней (A2-продукция): сильная дорожка тянет слабую.
4. Рецептив-впереди подаём как ресурс, не стыд (снимает аффект).
5. Месячный срез пересобирает дорожки.

## Что требует специалиста (не продукт-команда)
Точная последовательность грамматики/лексики по частотности+зависимостям, пороги стадий, дизайн EIT/speaking-рубрик — **нужен SLA/assessment-специалист** (open_questions_v2).
