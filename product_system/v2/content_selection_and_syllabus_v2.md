## Силлабусы (структура, не наполнение)
1. **Core lexical:** частотные слои под цель; каждая единица — с направленным статусом; депт (семьи/смыслы).
2. **Core grammar:** конструкции по частотности+зависимостям; фокус — процедурализация имеющегося (present perfect, conditionals, reported speech, passive, relative, aspect).
3. **Core phraseology:** коллокации (Academic Collocation List, корпусные) + фразовые (PHaVE — частотные значения) + формульные фреймы дискурса. **Приоритетный слой для ЦА.**
4. **Pronunciation:** проблемные для RU-L1 сегменты+просодия+связки (см. RU-профиль ниже).
5. **Communicative-functions:** CEFR-функции по стадиям (мнение, несогласие, нарратив, аргумент, repair).
6. **Content-topic map:** темы ↔ цель ↔ материал (кино/книги/подкаст/своё видео).
7. **Recycling map:** когда единица возвращается (SRS + переиспользование в задачах разных недель).

## Что НЕ делаем сейчас (stop condition)
- НЕ строим большие библиотеки контента (P0 запрещает).
- НЕ выдумываем корпусные проценты — при наполнении сверять с указанными корпусами.
- MVP-срез (validation_v2) использует ОДИН вручную-собранный интегрированный микро-юнит, не конвейер.

## Что требует специалиста
Финальная последовательность лексики/грамматики/фразеологии, пороги покрытия, отбор фразовых по PHaVE-значениям — **SLA/curriculum-специалист + корпусные данные**. Продукт-команда строит структуру/пайплайн, не лингвистические решения.
