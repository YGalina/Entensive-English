## Пересмотренная главная идея продукта
**Мост для high-knowledge / low-access взрослого:** не «активация речи» и не «чанки», а **система, которая (1) достраивает недостающие слои компетенции по ВСЕМ навыкам и (2) переводит знание в точное, беглое, самостоятельное употребление — через направленное извлечение, процедурализацию и вывод с обратной связью, держа тревогу ниже блокирующего порога.** Психология поддерживает обучение, не заменяет его и не претендует на терапию.

## ФИНАЛЬНЫЙ СИНТЕЗ (12 ответов)
1. **Валидны:** направленное извлечение; вход не создаёт речь; тревога блокирует извлечение; вовлечённость≠владение; ОС подсказками; интервальность; перенос — цель; фразеология недотренирована; трекать раздельно; автоматизм=скорость+стабильность.
2. **Переоценено:** «chunk вместо слова»; «4/3/2 центральный»; «тот же день»; «6 дорожек» как число; «убрать все стрики»; «≤4 строки»; «50:50»; «reps=активно»; стражи как «доказанная система».
3. **Развернуть:** chunk→наряду со словом; 4/3/2→условно; transfer/скорость→косвенные не «proof»; срез→мерить обучение; стражи→в границах Phase 9.
4. **Неизвестно:** вход:выход; доза до автоматизации; перенос AI→человек; долговечность; тайминг ретрива; письмо→говорение; эффект мини-лекций/резюме/стражей.
5. **Идея:** см. выше (мост high-knowledge/low-access, оба направления, психология в границах).
6. **Архитектура B1→B2:** 5 стадий (S0–S4) × ~25 дорожек, план ведёт узкое место, материал сверху тянет продукцию снизу; core+remediation+elective+cultural+live+coaching; режимы нагрузки без обещания срока (curriculum_blueprint_v2).
7. **Наименьший эксперимент:** ОДИН интегрированный микро-юнит (тема «работа», ~13 объектов разных типов, полный цикл вход→noticing→ретрив→guided→freer→ОС→retry→day+1→delayed→transfer), пилот 5–10, мерить удержание+перенос+аффект (validation_v2).
8. **Не строить пока:** community/носители, конвейер контента, БД-миграция, полная B2-карта, сложный AI, масс-генерация, оплата-в-масштабе.
9. **Требует Галину:** decision log ниже.
10. **Требует SLA/assessment/психолога:** прогрессия лексики/грамматики/фразеологии по частотности+зависимостям; пороги стадий; EIT/speaking-рубрики; отбор фразовых (PHaVE); тексты стражей+disclaimer-каркас; внешняя валидация CEFR.
11. **Может продукт-команда:** структура данных (7 сущностей), навигация-эксперимент, трекинг/флаги, лесенка-скаффолд, wire feedbackFor, кросс-платформа, приватность.
12. **Fable5 — следующее, по порядку:** (после разморозки и решений Галины) 1) собрать ОДИН микро-юнит вручную; 2) лесенка «сказать своё»+retry; 3) wire feedbackFor+тренер-резюме (эвристики); 4) day+1/delayed продуктивный ретрив; 5) трекинг+флаги; → провести пилот 5–10; → по сигналу P1.

## DECISION LOG ДЛЯ ГАЛИНЫ (только то, что требует её выбора)

### D1 · Навигация: инструменты или режимы?
- **Почему важно:** влияет на «зоопарк модулей» и ощущение цельности.
- **Опции:** (A) 5 табов-инструментов (текущий); (B) режимы Today/Learn/Immerse/People/Progress; (C) гибрид Today+2–3 режима+Progress.
- **Следствия:** A — знакомо, риск дробления; B — по намерению, но «Learn» может распухнуть; C — баланс.
- **Рекомендация:** C. **Уверенность:** средняя. **Доказ:** [B] — валидировать юзабилити.

### D2 · Тон обратной связи: только резюме после, или мягкие подсказки по ходу?
- **Почему важно:** «училка перебивает» убивает WTC; но immediate prompts в управляемой практике доказаны.
- **Опции:** (A) только тёплое резюме ПОСЛЕ (твоё предпочтение); (B) резюме после + опциональные мягкие подсказки в controlled-упражнениях (не в свободной речи); (C) пусть пользователь выбирает.
- **Следствия:** A — максимум безопасности, чуть меньше корректирующей силы; B — больше обучения, риск «поправляют»; C — сложнее.
- **Рекомендация:** B (подсказки ТОЛЬКО в упражнениях, свободную речь не трогаем). **Уверенность:** средняя. **Доказ:** [R prompts] + [F твоё] — тестировать на пилоте.

### D3 · Стрик/постоянство: как показывать?
- **Опции:** (A) только «дни практики в июле» (без «подряд»); (B) мягкая серия «N дней, пауза не рвёт»; (C) без серий вовсе.
- **Следствия:** A — безопасно; B — habit-поддержка, но риск давления; C — теряем habit-якорь.
- **Рекомендация:** A. **Уверенность:** высокая. **Доказ:** [R] shame-loop у ЦА; [F].

### D4 · Русские традиции в позиционировании (Петрусинский/Китайгородская)
- **Почему важно:** маркетинг vs честность.
- **Опции:** (A) не упоминать методы, говорить о результате; (B) упоминать как «наследие интенсивного погружения», без «ускорения»; (C) убрать полностью.
- **Следствия:** A — безопасно; B — история как капитал, если строго без «25×/подсознание»; C — теряем нарратив.
- **Рекомендация:** B, только про пересечение с доказанным (погружение/взаимодействие/интенсивность). **Уверенность:** средняя. **Доказ:** [R] пересечение; [U] отличительные механизмы.

### D5 · Оценка произношения
- **Опции:** (A) без ASR-оценки, ориентир-сравнение волн (текущее, [F твоё]); (B) добавить ASR-сегменты позже; (C) не трогать произношение как метрику.
- **Следствия:** A — безопасно, без «красного»; B — точнее, стоимость+риск «училки»; C — теряем канал.
- **Рекомендация:** A сейчас, B — открытый вопрос на потом. **Уверенность:** высокая (для сейчас). **Доказ:** [R] сегменты тренируемы; [F] против приговора.

### D6 · Что войдёт в bootcamp «поддержка куратора» (49€)
- **Почему важно:** обещание тарифа.
- **Опции:** (A) человек-куратор (недельный разбор+нагрузка); (B) только AI+структура; (C) гибрид AI-ежедневно + человек 1/нед.
- **Следствия:** A — дорого/качество; B — дёшево/слабее; C — баланс (MVP-A каркас есть).
- **Рекомендация:** C. **Уверенность:** средняя. **Доказ:** [R] человеч. подотчётность; [U] дозировка.
