## Зависимости (сначала — они, не фичи)
- **Research:** оптимум вход:выход [U]; доза до автоматизации [U]; перенос AI→человек [U]; формат стражей [U]. → часть решается пилотом, часть литературой/специалистом.
- **Curriculum:** нужен минимальный интегрированный микро-юнит (объекты разных типов + связный отрывок + L1-ловушка) ДО среза. Полная прогрессия — специалист.
- **Prototype:** для среза — лесенка «сказать своё», wire feedbackFor, retry, next-day+delayed ретрив, transfer-задача, трекинг.
- **Product:** навигация (режимы?), 7-сущностная модель, кросс-платформа.
- **Scale:** сообщество, контент-автоматизация, оплата, аналитика.

## P1 — после подтверждения сигнала
chunk/коллокации/фразовые как единицы (наряду со словом); контекст-фаза = связный отрывок; task repetition (fluency-нить, 4/3/2 VALIDATE); levelcheck v3 (двойная шкала+untrained); единый флеш-круг; 7-сущностная модель; mood→завтра; страж-в-момент (в границах).

## P2 — связная бета
web-Мастерская; Прогресс/карта 6 дорожек; лендинг+Галина; пуши/письма; входы pricing/login (paywall после 1-й сессии); месячный срез; структурированный AI-диалог; навигация по режимам (по итогам сравнения); consistency вместо стрика.

## P3 — масштаб/экосистема
community pilot (клуб/peer/встречи, по гейту); носители (обменная модель); контент-конвейер (корпуса+специалист); мини-лекции-генерация; аналитика; A/B (после ~200 активных).

## Дорожки
- **Mobile:** P0 (все) → P1 (chunk-выход, task rep, mood, страж) → P2 (компакт-прогресс, пуши, срез).
- **Web:** P0 (лесенка, feedback) → P1 (levelcheck v3, связный контекст) → P2 (Мастерская, Прогресс, лендинг, оплата).
- **Backend:** P0 (трекинг, ретрив) → P1 (7-сущностей вью-агрегат) → P2 (БД Drizzle, синк v2).
- **AI:** P0 (feedbackFor эвристики+резюме) → P2 (структ. диалог) → P3 (мини-лекции). Строго после вывода (дефолт).
- **Content:** P0 (1 юнит вручную) → P1 (немного юнитов) → P3 (конвейер+корпуса+специалист).
- **Community:** P3 (не раньше; по confidence-гейту).

## Критический путь
P0-микро-юнит + feedback + retention/transfer-замер — БЛОКИРУЕТ всё: без учебного сигнала P1+ = преждевременно. Curriculum-специалист блокирует масштаб контента. 7-сущностей блокирует кросс-платформу и приватность-в-масштабе.
