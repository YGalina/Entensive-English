# Реестр доказательств и решений · v2

Дата: 2026-07-13 · (PHASE 1 доп.) Прослеживает цепочку доказательство→решение для каждого продуктового выбора. Уровни: **A** принцип · **B** гипотеза · **C** опция. Метки силы: [R][P][H][F][U].

## Принципы уровня A (ведут систему)
| Принцип | Цепочка доказательство→решение | Сила |
|---|---|---|
| Извлечение направлено-специфично; продукция — отдельная цель | retrieval effect специфичен направлению (gap §5) → тренировать смысл→форма отдельно | [R] Strong |
| Многословные единицы недотренированы (наряду со словом) | формульный разрыв глубже (gap §7) → phraseology — отдельная дорожка, НЕ замена слов | [R] Moderate |
| Трекать навыки раздельно (не один ярлык) | компетенция многокомпонентна (CEFR) → 6 дорожек / диагностика по дорожкам | [R/P] Strong |
| Автоматизм = скорость + стабильность | Segalowitz/Logan → мерить латентность И вариативность | [R] Moderate |
| Перенос — цель (измеряется косвенно) | transfer = реальная компетенция → untrained items в оценке | [R] Strong (важность) |
| Тревога блокирует извлечение | тревога занимает РП (Eysenck; Botes) → аффект-поддержка контекстно | [R] Strong |
| Вовлечённость ≠ владение | engagement≠proficiency (консенсус) → не стрик/минуты как обучение | [R] Strong |
| Вход не создаёт речь сам по себе | экстенс. чтение/погружение без output = пассив (gap §9) → output обязателен | [R] Strong |
| ОС подсказками > переформулированиями | Lyster&Saito; Li → prompts, не «красная ручка» | [R] Strong |
| Интервальное извлечение | Kim&Webb; Cepeda → SRS позвоночник | [R] Strong |

## Гипотезы уровня B (валидировать)
Ранний продуктивный ретрив (тайминг?) · fluency-нить (task repetition; 4/3/2 условно) · тренер-резюме после как дефолт · consistency вместо стрика · гейт сообщества по готовности · баланс вход:выход (~output>«капли») · платформенные дефолты · наш формат стражей · навигация по режимам (C) · «make your own sentence» с лесенкой · word flood как прайминг.

## Опции уровня C (варьируются)
Конкретный набор «6 дорожек» · число артефактов до клуба · лимиты печати mobile · порог reps «активного» (заменить латентностью) · immediate vs delayed prompts · тёмная тема глобально/только focus.

## Founder-предпочтения [F] (держим как решения, не как доказательства)
Убрать медитации/дыхание/ботанику · Галина только лендинг/письма · тренер-резюме текстом (не перебивать вслух) · мини-лекции инфографикой · YouTube-импорт «переведи свою жизнь» · тон без эмодзи/«молодец» · bootcamp с куратором.

## Неизвестное [U] (open_research_questions_v2)
Оптимум вход:выход · доза устных употреблений до автоматизации · перенос AI→человек · долговечность после интенсива · перенос письмо→говорение · время декларатив→процедура · эффективность мини-лекций/тренер-резюме · формат стражей.

## Противоречия (обе стороны)
TBLT величина (0.93/0.61) · 4/3/2 и сложность (Nation↑/Boers↓) · immediate/delayed feedback · целенаправленная практика (сильная форма оспорена) · русские интенсивы (созвучны в погружении/взаимодействии, не в «ускорении»).
