## Навигация: «зоопарк модулей»?
v1 (5 табов инструментов: Сегодня/Библиотека/Словарь/Люди/Профиль) риск дробления. Сравниваем 3 варианта:
- **A. По инструментам (текущий):** знакомо, но легко расползается в модули.
- **B. По учебным режимам:** Today · Train · Immerse · Practise-with-people · Review. Плюс: связывает по НАМЕРЕНИЮ, не по инструменту; меньше «зоопарк». Минус: «Train» может стать свалкой.
- **C. Гибрид:** Today (ведёт) + 2–3 режима (Learn/Immerse/People) + Progress + Profile.
**Рекомендация [B, тестировать]:** склоняемся к C — режимы, но без догмы; НЕ принимать автоматически (бриф). Решает валидация + founder-вкус. Ключ: один вход «Сегодня» ведёт, остальное — по намерению, не по списку упражнений.
