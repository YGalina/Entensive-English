## Учебная функция каждого таба

### Сегодня — «один следующий шаг» + ритм дня
- Сессия дня (единственный терракотовый CTA): **поток chunk → связный контекст → сказать своё (лесенка)**. Автостарт потока.
- Короткий флеш-круг «пора вернуть слова» (SRS produce+recognize единой очередью, финал — своя фраза).
- Вечером экран сам → вечерний круг (состояние→страж→статус, влияет на завтра).
- Возвращение после паузы: «Вернуться с 5 минут».
- Вчерашнее тренер-резюме (карточка, читается).
- Стражи — по триггеру/после события, НЕ постоянной карточкой.
Учебно: daily guidance + habit. Методика: один цикл, не 8 модулей.

### Библиотека — вход + слушание + произношение
- Слушать (shadowing-караоке, comprehension-гейт до имитации), Читать (тап-перевод, короткие сессии), Звуки (лестница темпа/произношение — вслух в наушники), полка дня, YouTube-поиск/импорт.
- Каждый контент → extraction + 1 output (не воркшит-фабрика).
Учебно: listening decoding, pronunciation, incidental+extraction.

### Словарь — извлечение + биография слова
- Лента слов (биография: где встретила, статусы new→recog→mine), единый флеш-круг.
- «Моим» слово становится после активного вывода.
Учебно: short retrieval, направление смысл→форма.

### Люди — interaction (по confidence-гейту)
- До 5 артефактов: «позже, когда будешь готова». После: Практика 10 мин, клуб-вход, встречи+чек-ин, чат.
Учебно: guided→real interaction, WTC, перенос.

### Профиль — пульт + компакт-путь
- Языки/голос/темп/приватность/**напоминания**; компакт-путь: честные часы + 3 «я теперь могу».
Учебно: metacognition (компакт), study habits.

## Активности mobile (методическое обоснование)
| Активность | Почему mobile | Формат |
|---|---|---|
| daily guidance | один шаг в кармане | карточка сессии |
| short retrieval | микро-очереди в паузах жизни [R spacing] | флеш-круг 4 мин |
| listening | наушники на ходу | караоке+тап |
| pronunciation | вслух интимно наедине | лестница темпа |
| voice response | голос привычен в телефон [H] | запись, приватно |
| phrase review | биография+SRS | словарь |
| guided speaking | сказать своё с лесенкой | текст/голос+чипы |
| habit support | пуш = зов; «вернуться с 5 мин» | notifications |
| reflection | вечер у кровати | вечерний круг |
| real-world missions | гео, «я на месте» | встречи/чек-ин |

## Чего на mobile НЕТ (переносится на web)
Набор (клавиатура), грамматика-конструктор, длинное письмо (>4 строк), карта пути с аналитикой, длинные AI-сессии, авторинг, live клуб-комната. Обоснование — mobile_web_learning_split.md.

## Оффлайн (методика: доступность [R])
Сессия дня, SRS-очередь, скачанное чтение — работают без сети. «Снова онлайн» → мятная синхронизация «всё на месте».
