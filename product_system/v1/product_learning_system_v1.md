# Продуктовая система обучения · v1 (головной файл)

Дата: 2026-07-13 · Product & Learning Systems Architect · КОД ЗАМОРОЖЕН.
Источник истины: `learning_architecture/current/` (утверждённая методология). Метки [R][P][H][F][U] — см. evidence_register.
Правило: не изобретать механик, противоречащих методологии. Конфликты легаси — называть явно (см. legacy_migration_plan.md).

## Инварианты (из методологии — нельзя нарушать)
1. Единица — **chunk**, не слово. 2. Извлечение **смысл→форма в тот же день**. 3. Нить **fluency T4→T5** (повтор с вариацией, 4/3/2). 4. Вывод **с обратной связью** (prompts; тренер-резюме ПОСЛЕ, не перебивая). 5. **Аффект — гейт** (стражи в момент, не декор). 6. Неровный профиль — **6 дорожек**, не один ярлык. 7. Убрано: медитации/дыхание/ботаника, стрик-«подряд», «вал в подсознание». 8. Галина — только лендинг/письма. 9. mobile=ритуал/голос/микро; web=клавиатура/глубина/картина. 10. Вовлечённость ≠ владение.

## TASK 1 · Журналы обучения (8)

Каждый журнал = вход-состояние → что система делает → какие поверхности → критерий успеха. Все опираются на competence_model + progression.

### 1. Первый раз
Вход: неровный A2–B1, стыд, «опять анкета?». → онбординг 4 шага (язык мышл.+интерфейс раздельно → цель → время+уровень → барьер-страж) → **levelcheck v3** (понимание/речь ОТДЕЛЬНО, «слух впереди — ресурс») → первая сессия сразу, **финал = своя первая фраза** (сильнейший retention-момент [обе симуляции]). Поверхности: mobile или web. Успех: 1 артефакт создан в день 0; нули холодного старта скрыты.
Конфликт легаси: онбординг 9-шаговый с факт-экранами; levelcheck 18 слов узнавание. → REDESIGN.

### 2. Неровный B1
Вход: reading B2 · listening B1 · productive vocab A2 · speaking A2. → диагностика по дорожкам → **план ведёт узкое место** (грузим продуктивное извлечение+chunks, не чтение) → материал берём из верхней дорожки (интересное чтение), извлечение — на нижней. Поверхности: web для чтения/анализа, mobile для извлечения/речи. Успех: продуктивный словарь растёт быстрее рецептивного; ярлык не показан как приговор.
Конфликт: один уровень-ярлык в prefs. → расширить модель (см. progress).

### 3. Ежедневный 20 мин
Вход: занятая взрослая, карман. → «Сегодня» = один шаг: сессия 12 мин (поток chunk → связный контекст → сказать своё с лесенкой) + короткий флеш-круг + вечерний круг 3 мин. Поверхности: mobile only. Успех: день закрыт по «сделала главный цикл», не по 8 модулям.
Конфликт: dayplan закрывает день по 8 hidden-модулям; «Сегодня» — чек-лист. → REFACTOR (DayCycle vs SkillCatalog).

### 4. Интенсив 90 мин
Вход: bootcamp/accelerated, есть время и стол. → утро mobile (сессия+речь) → день web-«Мастерская» (письмо с опорами, грамматика-конструктор, диалог с персонажем, мини-лекция→отработка, длинная AI-сессия) → вечер mobile (круг). Поверхности: mobile+web в один день, общий бэкенд. Успех: 50:50 вход:выход [H]; куратор следит за нагрузкой; день отдыха обязателен.
Конфликт: web-«Мастерской» нет; длинные форматы на mobile. → BUILD web Мастерская.

### 5. Возвращение после паузы
Вход: пропуск 3–10 дней, хрупкость, риск не вернуться совсем. → **отдельный маршрут «Вернуться с 5 минут»**: micro-session на реактивацию забытого (SRS достаёт просевшее), копия без стыда «всё на месте», НЕ стандартный большой «Сегодня». Поверхности: mobile (+1 письмо/пуш языком частей, один раз). Успех: реактивация; «дни практики», не «стрик сгорел».
Конфликт: return-route нет; стрик-«подряд» где остался; mood пишется, но не влияет. → BUILD + REMOVE streak.

### 6. Готовится к реальному разговору
Вход: собеседование/встреча через неделю. → цель-режим «закрыть speaking gap на теме X» → неделя chunks+фреймы по теме → диалог с персонажем (AI-ход) → 4/3/2 под временем → клуб/трен. как репетиция → тренер-резюме после. Поверхности: mobile голос, web длинный диалог/письмо, live клуб. Успех: фреймы выходят без сборки на новом содержании (T6-перенос).
Конфликт: диалога с персонажем/AI-хода нет; 4/3/2 нет. → BUILD.

### 7. Со страхом речи
Вход: замирает у микрофона (де-автоматизация под стрессом — 19). → лесенка к голосу: текст → шёпотом → вслух (практика стража запугивания) → **страж в момент** при заминке перед записью (называем часть, даём место, идём дальше) → запись приватна, ноль красного → тренер-резюме тёплое ПОСЛЕ. Поверхности: mobile. Успех: голосовой артефакт без удаления; freeze проходит.
Конфликт: страж — карточка на главной, не триггер; фидбэк на речь отсутствует (feedbackFor не подключён). → REDESIGN + wire.

### 8. Готова к сообществу
Вход: есть 5+ своих фраз, уверенность выросла (confidence-гейт). → «Люди» раскрывается: peer «Практика» 10 мин → онлайн-клуб 6 (вопрос на столе, опоры, «хочу сказать», SOS) → офлайн-встреча (разогрев→бейдж→доска фраз→в словарь). Поверхности: mobile (гео/чек-ин), web/desktop (клуб-комната live). Успех: доброволь­ная реплика на людях; фразы встречи → словарь.
Конфликт: люди предлагаются на день 1 (пугает); клуб — заглушка (нужен бэкенд). → gate + BUILD (community pilot).

## TASK 2 · Поверхности продукта и их учебная функция

| Поверхность | Учебная функция (перво) | Что НЕ делает |
|---|---|---|
| **Mobile app** | привычка + голос + микро-извлечение + рефлексия + аффект-поддержка + реальные миссии | длинное письмо, глубокий анализ, аналитика |
| **Web app** | глубокая работа: письмо, грамматика-конструктор, транскрипт/сцена, длинное чтение, картина прогресса, длинные AI-сессии | ритуал у кровати, гео-миссии |
| **AI-тренер** | corrective feedback **строго после вывода**: понял→1 подсказка(prompt)→вариант→ретрай; тренер-резюме текстом (палитра «ещё так говорят», идиомы/цитаты, мини-лекция→отработка) | болтовня-чат до вывода; перебивание вслух; «AI-friend» |
| **Live coach** | недельный разбор (факты→фокус), куратор bootcamp, человеческая подотчётность | замена ежедневного ядра |
| **Peer group** | interaction низкие ставки, WTC | экспертная коррекция (peer≠expert) |
| **Native-speaker** | аутентичный вход/норма, культ. обмен | коуч (носитель≠учитель [R]); двусторонний обмен |
| **Film/book clubs** | общий крючок → дискурс/обсуждение, перенос | воркшит-фабрика (макс 1 output/единицу) |
| **Offline missions** | перенос в реальный мир (T6): кафе, прогулка, «я на месте» | тренажёр (это тест переноса) |
| **Assessment** | понимание/речь ОТДЕЛЬНО; месячный срез (vocab+listening+2-мин speaking+3-строки writing); внешняя валидность | ярлык как достижение; сдать≠функционировать [R] |

Все поверхности пишут в **общий бэкенд** (один LearningObject-стор + журнал событий) — прогресс перетекает без швов (см. learning_data_model.md).
