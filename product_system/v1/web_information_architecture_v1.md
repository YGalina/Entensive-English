## Учебная функция каждого раздела

### Сегодня — рабочий стол
- Сессия-focus ИЛИ **«глубокая работа дня»**; отражает телефонный прогресс: «утренняя сессия сделана на телефоне ✓ — вот глубокая работа».
Учебно: не копия mobile; направляет в deep work.

### Мастерская (НОВОЕ) — deep work на клавиатуре, 20–40 мин
- **Письмо** с опорами (входящее слева, редактор справа, страж-перфекционизм над «Отправить»).
- **Грамматика-конструктор** (образец/закон слева — сборка справа; listen-then-build; «скажи через X»).
- **Набор** (машинопись, моторный канал — физич. клавиатура).
- **Диалог с персонажем** (письменный/длинный ход AI после реплики).
- **Мини-лекции с инфографикой** (времена/устойчивые выражения — таблицы дышат) → ведут в отработку.
Учебно: proceduralization, writing, complexity (pre-task planning-ресурс).

### Библиотека — глубокий вход
- Сетка B1–C1 + импорт; **параллельное чтение EN/RU колонками**; shadowing на большом экране (транскрипт 2 колонки + сравнение записи); анализ сцены/транскрипта.
Учебно: longer reading, transcript/film analysis, extraction.

### Мой словарь — таблица + рейка SRS (есть)
Учебно: обзор корпуса, статусы, очередь.

### Сообщество — клубы live
- **Клуб-комната (браузер)** 6 человек; «кто рядом» на карте (только район); встречи.
Учебно: interaction, перенос; live стабильнее за столом.

### Прогресс — большая картина
- **Карта пути к B2** (5 уровней, «ты здесь»); срезы понимание/речь ОТДЕЛЬНО; дневник-архив с поиском; 6 дорожек; «что я теперь могу» наверху, часы — вторым слоем.
Учебно: outcome-мотивация, metacognition, transfer-evidence.

### Профиль — аккаунт/оплата/настройки; Лендинг — витрина; Кабинет автора (future).

## Активности web (методическое обоснование)
| Активность | Почему web |
|---|---|
| larger visual field | параллельные колонки EN/RU не влезают на телефон [R] |
| focused work | 20–40 мин deep work, низкое врем. давление |
| longer reading | глубокое чтение с переводом рядом |
| writing | письменный лексикон отдельен [R]; клавиатура |
| grammar analysis | конструктор = deep work |
| transcript work | shadowing-разбор, сравнение волн |
| film scene analysis | пауза/разбор на большом экране |
| book work | главы, параллельный текст |
| progress analysis | плотность данных, карта |
| lesson planning | режим/цель/фокус недели |
| portfolio | дневник-архив артефактов |
| longer AI sessions | развёрнутый диалог, письменно |
