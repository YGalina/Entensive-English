# Intensive English — центр управления владельца

> Это первый экран проекта в Obsidian. Здесь видно, что строится, что уже существует, что ждёт решения Галины и что запрещено реализовывать без её финального утверждения.

## Стоп-сигнал сейчас

**Разработка новых пользовательских экранов остановлена.** Текущий первый запуск и День 1 не приняты как цельный опыт. Отдельные ранее принятые экраны и исправления не означают утверждение всей цепочки.

Текущий gate: **Fable должен показать один связный кликабельный/обзорный поток первого запуска → оценки → Дня 1 → обратной связи → завершённого дня. Только после проверки Codex и явного решения Галины `УТВЕРЖДАЮ UX/UI` разрешается реализация этого потока.**

## Как Галина контролирует проект

Для каждого крупного блока используется одинаковая последовательность:

`Аналитика → продуктовый/методический контракт → полный UX flow → Fable UI → проверка Codex → решение Галины → реализация → QA устройства → решение Галины о выпуске`

Решение Галины всегда отдельное и явное:

- `УТВЕРЖДАЮ КОНЦЕПЦИЮ` — разрешает перейти к полному UX;
- `УТВЕРЖДАЮ UX` — разрешает визуальный дизайн;
- `УТВЕРЖДАЮ UX/UI` — разрешает реализацию показанного пакета;
- `ПРИНИМАЮ СБОРКУ` — закрывает device QA;
- `РАЗРЕШАЮ РЕЛИЗ` — единственное разрешение на выпуск.

Молчание, просмотр файла, прошлое частичное одобрение и технический PASS Codex **не считаются** решением владельца.

## Что Codex обязан показывать перед реализацией

- весь пользовательский путь, а не два отдельных экрана;
- все состояния: default, loading, empty, error, denied, resumed, completed;
- точный текст на экранах;
- что происходит после каждой кнопки;
- что сохраняется и какая обратная связь появляется;
- варианты 360×800, 390×844 и 200% текста;
- список того, что не входит в блок;
- один экран/документ для решения владельца с вариантами `утвердить / вернуть на исправление / отклонить`.

## Следующее решение владельца

Сейчас от Галины **ничего утверждать не требуется**: полного Fable-потока ещё нет. Следующий материал на утверждение — единый обзор первого запуска и Дня 1. До него реализация новых экранов запрещена.
