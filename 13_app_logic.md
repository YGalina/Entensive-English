## 0. Продукт одним абзацем

**Intensive English — система взрослой языковой тренировки для тех, кто понимает английский, но не говорит.** Целевой пользователь — взрослый B1–B2 (часто экспат), у которого слух впереди речи. Продукт закрывает именно этот разрыв: массивный вход живым контентом (метод Петрусинского/Лозанова — сверхнасыщенное поле, перегрузка → активизация в контексте → узнавание) **плюс обязательный ежедневный активный вывод** (наука: разрыв закрывается только производством речи). Прогресс — честные часы и «что я теперь могу», не стрики и баллы. Психологическая опора — работа с частями (4 стража). **Лицо и история Галины — только на лендинге и в письмах (решение Галины 2026-07-12): в самом приложении её именованного присутствия нет, остаётся только тон.**

Формула доверия (из аудита): *много входа, много смысла, мягкое состояние, ежедневный маленький выход в речь, честные часы, видимый результат в жизни.*

## 1. Десять принципов (проверять каждый экран)

1. **Один следующий шаг.** На любом экране понятно, что делать дальше, без объяснений. Если блоку нужен текст «зачем это» — блок лишний. Один терракотовый CTA на экран.
2. **Каждый цикл заканчивается активным выводом.** Сессия, флеш-круг, чтение, shadowing, грамматика — всё завершается тем, что человек говорит или пишет своё. Говорение — финал цикла, а не отдельная кнопка на главной.
3. **Массив, не капля.** Единица обучения — блок (пачка слов + контекст), не карточка. Ничего не гейтим по числу слов. Критерий приёмки: «усиливает сверхнасыщенный ввод — или дробит?»
4. **Перевод всегда рядом.** Один тап/клик — слой перевода. Не заставляем продираться и гадать.
5. **Честные часы, не стрики.** Считаем реальное время практики. Пустой день — тихий столбик: «пауза, не потеря». Ориентиры уровня — часы CEFR (180–220 ч/шаг), всегда «ориентир, не обещание».
6. **Красного нет.** Поправка — роза #C75A7A, всегда со следующим шагом. «Не знаю» / «не помню» — легальный ответ без штрафа, слово просто вернётся раньше.
7. **Стражи — части, не враги.** С чувством не спорим и не заклеиваем аффирмациями: назвать → увидеть живым → дать место → маленький шаг рядом с чувством. Страж появляется по детектору из поведения, не по расписанию.
8. **Приватность по умолчанию.** Записи речи и дневник — только у пользователя; в «Кто рядом» — только город и район; отказ от чего угодно — без объяснений. Синк текстов/аудио — только по согласию.
9. **Без манипуляций — везде.** Продаём режим и поддержку, а не чудо. Напоминание до списания, отмена в два тапа, бесплатный режим навсегда, «остаться на бесплатном» тем же кеглем. Пуш/письмо — факт и приглашение, не вина. Никогда: «стрик сгорит», «мы скучаем», «C1 за 3 месяца», «980 слов в подсознание», «альфа-волны ускоряют».
10. **Тон взрослого тренера.** Спокойно, точно, без сахарной похвалы и эмодзи. Именованное присутствие Галины — ТОЛЬКО лендинг и письма (решение 2026-07-12), в приложении — её тон без её имени. Английские строки — Lora, интерфейс — Golos Text.

## 2. Карта состояний пользователя

### 2.1 Путь снаружи внутрь

```
Лендинг («Ты уже понимаешь. Пора заговорить») / стор
   ↓                            ← лицо и история Галины живут ЗДЕСЬ (решение 2026-07-12)
Вход: Apple · Google · почта magic-link (пароля нет)          ← новичок
   ↓
Онбординг · 4 шага ≤ 90 сек (факт-экраны из легаси-квиза → в письма и лендинг):
   язык мышления (+язык интерфейса отдельно) → жизненная цель →
   честное время + уровень → барьер-страж
   ↓ («не уверена?»)
Проверка уровня · 3 мин («не экзамен, а настройка»; «не знаю» — кнопка;
   результат = рабочая зона: понимание и речь ОТДЕЛЬНО)
   ↓
«Сегодня» — первый день                                        ← вернувшийся: сразу сюда
```

- Вернувшийся пользователь: экран «С возвращением» → magic-link → «Сегодня». Твои часы, слова и клуб на месте.
- РФ-режим: без Apple/Google — почта magic-link остаётся законным путём (`03_spec_MVP.md`).
- Три обещания приветствия = продуктовые инварианты: честные часы · перевод рядом · ошибка не красная.

### 2.2 Состояния дня (главный цикл — §3)

Утро → сессия дня → (день: SRS-круг, библиотека, люди) → вечерний круг → закрытие дня.

### 2.3 Состояния недели и уровня

- **Неделя**: часы столбиками; клубная встреча (онлайн вт/чт, офлайн сб); «Сессия с тренером» — еженедельный разбор (факты недели → 3 вопроса → один фокус). Состояние вечернего чек-ина влияет на завтрашний план: «устала» → короче, «заряжена» → больше речи.
- **Месяц/уровень**: срез Assessment (levelcheck + 2-мин speaking sample); «Что я теперь могу» пополняется способностями (Capability) из артефактов; часы до следующего уровня — 86 ч из ~200, «ориентир, не обещание».

### 2.4 Края (обязательные состояния, все — без вины и красного)

| Состояние | Логика |
|---|---|
| **Пустой словарь / пусто где-либо** | Объясняем «почему пусто» + приглашение: «слово попадает сюда, когда тапаешь перевод в контенте» |
| **Офлайн** | амбер, не красный; «часы идут и без сети»; список «доступно сейчас / вернётся с сетью»; сессия дня и SRS скачаны |
| **Снова онлайн** | мятная синхронизация: «✓ всё на месте, ничего не пропало» (записи, слова, минуты) |
| **Ты остановилась** (пауза перед записью/речью) | «Страж в моменте»: называем часть («это обесценивание»), формула места, две кнопки — «Я увидела её — говорю дальше» / «Сделать паузу на минуту» |
| **Возвращение после паузы дней** | одно письмо/пуш языком частей, «вернуться с 5 минут»; никаких «мы скучаем» |
| **Карта не прошла** | роза, факты + следующий шаг; доступ сохранён 7 дней; «остаться на бесплатном — тоже нормально» всегда видно |

## 3. Цикл дня (ядро продукта)

### 3.1 Утро — «Сегодня»

Экран «Сегодня» = **один следующий шаг**: большая карточка «Сессия дня · 12 мин · из твоего подкаста…» с CTA «Начать» + честные часы месяца + малая карточка SRS «Пора вернуть слова · 7 карточек · 4 мин». Вечером экран сам трансформируется: сделанное сворачивается, появляется вход в вечерний круг. Ничего больше: ни «фразы о себе», ни отдельных кнопок produce/roles/3-минутки — это шум легаси, удалён.

Пуш утром (≤2 пуша/день, тихие часы 21:30–8:00, в focus — ничего): «Сегодня 12 минут из твоего подкаста. Одна фраза — и день начат.»

### 3.2 Сессия дня — ОДИН флоу, 4 фазы (12–30 мин)

Это движок блока из `05_method_to_mechanics.md`, надетый на макет 2b/v2. Прогресс фаз сверху, фаза = цвет навыка.

| Фаза | Что происходит | Метод |
|---|---|---|
| **1 · Настройка** | мягкий вход: дыхание, музыка (барокко), намерение. Коротко | снятие барьеров, состояние (регуляция, не «альфа-волны») |
| **2 · Поток слов** | автопрокрут пачки: слово + транскрипция + перевод + озвучка + пример. Темп 0,5 с безопасный (разгон — по явному согласию); «Ещё нет / Знаю» не останавливая поток; фон стабилен | перегрузка / киносеанс, массивный ввод |
| **3 · Контекст** | те же слова в живом отрывке (подкаст/видео/статья пользователя): 2 новых — амбер, знакомые — мятное подчёркивание; тап = слой перевода снизу («Прослушать · В мой словарь») | активизация в контексте; слова и контекст — две половины одного блока |
| **4 · Сказать своё** | вопрос дня по теме контекста + чипы сегодняшних слов + микрофон или текст: «2–3 фразы. Не идеально — достаточно хорошо для контакта». Кнопка «Засчитать в часы» → артефакт | pushed output; retrieval «значение→форма»; финал цикла всегда — вывод |

**Спектр форматов фазы 4** (подтверждено Галиной, ротация по дням/контенту):
- сказать своё голосом/текстом на вопрос дня (базовый);
- собери фразу по памяти после слушания (phrase builder: ухо ведёт, ответ не показан заранее);
- письмо 3–4 строки («ответь Марку» — настоящее письмо, не упражнение);
- «скажи это через present perfect» — грамматика как трансформация **своей** фразы;
- диалог с персонажем (перерождение легаси «Ролей»: реплика партнёра звучит, свою говоришь сама).

Вечерняя сессия (после 20:00 или вручную) идёт в **focus-палитре** «свет лампы»: фон #211D16, латунь вместо терракоты, навигация скрыта — только «Выйти из фокуса». Focus — среда двух ритуалов (сессия + вечерний круг), НЕ тёмная тема всего приложения и не идентичность.

### 3.3 День — необязательные, но живые входы

- **Флеш-круг SRS** («Пора вернуть слова», без долга): лицевая сторона — **твой контекст с пропуском**, не голое слово; самооценка честностью — «Помню и могу сказать / Узнаю, но не скажу / Пока не моё» (= интервал возврата, прозрачный SRS); финал круга — **активный вывод**: одна фраза с любым словом. Web-вариант: припоминание RU → вспомни EN, потом мягкая сверка.
- **Библиотека**: продолжить начатое, найти новое, импортировать своё (§4.2).
- **Люди**: клуб, встреча, «Практика» с соседом (§4.4).

### 3.4 Вечер — Вечерний круг (единственный обязательный тёмный экран)

Focus-палитра, заголовок «Тихо закроем сегодняшний день»:
1. **Факты дня** — минуты речи, новые слова (факты, не оценки);
2. **Как ты сейчас** — 4 взрослых состояния (Спокойна · Собой довольна · Устала · Тяжело было); ответ влияет на завтрашний план;
3. **Кто из стражей приходил** + «и ты всё равно…» — признание факта пути, не разбор;
4. **Одна фраза о дне по-английски** — с чипами из сегодняшних слов; «запись видна только тебе»; статусы копятся как дневник.
CTA «Закрыть день» (латунь). Подпись: «28-я запись подряд · все — только твои» (серия как факт, без угрозы сгорания).

Вечерний круг живёт и на web (полноценно, в focus) — web не «витрина», а полное приложение.

### 3.5 Что удалено из цикла дня (легаси)

| Легаси-вход | Судьба |
|---|---|
| «Фраза о себе» /phrase (OutputCard morning) | **удалить** — вывод живёт в финале сессии и в вечернем круге |
| Отдельные кнопки produce / roles / «3-минутка» на главной | **удалить с главной**: produce = фаза 4; роли = формат фазы 4 «диалог с персонажем»; дыхание 3-минутки = фаза 1 «Настройка» + «страж в моменте» |
| «Сегодня» как список 7 шагов dayplan | **упростить**: один следующий шаг (сессия) + SRS-карточка + вечерний вход. Dayplan-механика остаётся под капотом (что засчитано в часы), но не как чек-лист на экране |
| Стрик/огоньки где остались | тренировочный режим: «сегодня 12 минут»; серии — только как «N записей подряд, все твои» |

**Шесть навыков** (каждый со своим цветом; входы из Библиотеки и как фазы/форматы сессии, НЕ отдельные табы):
Слова #E8623D · Слух #D99A2B · Речь·видео #4A7BA6 · Чтение #A8465F · Грамматика #4FB286 · Письмо #8A5FA8.

- **Читалка**: перевод по тапу (mobile) / слой смысла справа (web); «читаешь для смысла, не для словаря»; финал «Сказать своё об этом».

- **Речь·видео**: посмотри → ответь своими словами на камеру, суфлёр поверх кадра, «никто не слушает, кроме тебя».

- **Групповой поток /flow** — отдельный трек с бэкендом (комната до 20, свой темп внутри общего дня); в v1-навигацию не входит, живёт за «Люди» когда будет готов.
- **3-минутка /three** — растворяется: дыхание = фаза «Настройка», микро-вывод = фаза 4.

### 4.2 Web — полноценное приложение (не витрина)

Сайдбар: **Сегодня · Библиотека · Мой словарь · Сообщество · Прогресс** + аватар (профиль).

- **Рабочий стол «Сегодня»**: три колонки — сайдбар · сессия дня (единственный яркий CTA) + SRS + клуб · правая рейка (часы, слово дня, «вечерний круг откроется после 20:00»).
- **Сессия дня** — один фокус-кадр на весь экран, тёмный «свет лампы», клик по слову = карточка перевода, «"сказать своё" ты завершишь речью».
- Сплит-паттерн web-навыков: **образец/контекст слева — мастерская справа** (грамматика: закон слева пока собираешь; письмо: входящее слева, редактор справа; речь: ролик слева, камера с суфлёром справа).
- Онбординг web: вопрос слева — **живой пример будущего контента справа** («так будет выглядеть твой контент»).
- Вход web: слово автора слева (цитата Галины + три обещания), вход справа.

### 4.3 Лендинг (гостевой, отдельно от приложения)

Блоки по макету: hero «Ты уже понимаешь. Пора заговорить» (+живой коллаж контента) → разрыв «понимаю ↔ говорю» (шкалы B1+/A2 — «типичный профиль на старте») → **библиотека** («самая большая библиотека для тех, кто уже понимает»: B1–C1 + ∞ своих видео, 1 мин от ссылки до тренировки) → программа и честные часы (CEFR-таблица) → **автор** (история Галины: школа в 12, метод, «тренер, не репетитор», психология внутри, интерес к людям) → **стражи** (4 части + практика частей) → сообщество экспатов → финальный CTA «Первая сессия — 12 минут. Первая фраза — сегодня» (7 дней бесплатно).

### 4.4 Люди — правила безопасности (проговорены текстом в UI)

- геолокация: только город и район, никогда точная; виден лишь тот, кто сам открылся; закрыться можно в любой момент, «никто не увидит, что ты был открыт»;
- отказ от «Практики»/встречи — без объяснений;
- клуб: 4 договорённости (ошибки приветствуются · можно просто слушать · только английский, мягко · сказанное остаётся здесь), жалоба в один тап, «SOS — выйти без стыда», «Хочу сказать» вместо очереди;
- минуты речи клуба → честные часы; фразы клуба/встречи → словарь;
- чат участника: только английский, ошибки приветствуются.

| Бесплатный режим | 0, навсегда | полноценная опция тем же кеглем |

Правила: paywall — после ценности; без таймеров скидок и фейковых зачёркнутых цен; напоминание за 3 дня до списания (письмо с кнопкой «Отменить продление»); отмена в два тапа без удержания; при отмене доступ до конца периода → бесплатный режим (словарь и часы остаются). **Гейтить нельзя по числу слов/день** (убивает массивный ввод) — гейтим по доступу к библиотеке/персонализации/AI-фидбэку/живым форматам.

Dunning: «карта не прошла» — роза, доступ 7 дней, «попробуем завтра / обнови карту / остаться на бесплатном»; максимум два письма (это и одно перед концом доступа), без «тревожных» повторов.

Письма (все по формуле: бумажная шапка + lockup, один CTA, честный футер «Отключить»): утренний план · подтверждение оплаты · напоминание о списании (с фактами года: «96 честных часов, 1240 слов») · оплата не прошла · возвращение после паузы (один раз, язык частей) · итог недели.

## 9. План рефактора (порядок)

Каждый шаг зелёный по проверкам (tsc web+mobile, unit, e2e, expo export) — web не ломается ни на одном шаге.

1. **Сессия дня = один флоу 4 фаз** (mobile + web): настройка → поток → контекст → сказать своё со спектром форматов. Самое главное и уже подтверждено Галиной.
2. **«Сегодня» дочищаем**: один шаг + SRS-карточка + вечерняя трансформация (много готово); убрать легаси-входы (§8).
3. **Табы**: mobile 5 (Сегодня·Библиотека·Словарь·Люди·Профиль), web-сайдбар 5; Путь → в Профиль.
4. **Флеш-круг 37a**: контекст с пропуском, три честных ответа, финал-вывод (готов частично — довести финал).
5. **Вечерний круг**: состояние → страж → статус (готов v2 — сверить с focus-макетом, добавить влияние состояния на завтра).
6. **Библиотека + Словарь** по макетам: поиск «% моего», импорт-урок, биография слова.
7. **Навыки** как входы (читалка-слой, shadowing 3 фазы, phrase builder, грамматика «закон из контента», письмо, речь-видео).
8. **Люди**: кто рядом, клуб-комната, встречи (UI поверх заглушек, бэкенд следом).
9. **Онбординг 4 шага + вход** по макетам (web-сплит). Приветствие Галины в приложении НЕ строим (решение 2026-07-12) — её экраны переезжают в лендинг; факт-экраны легаси-квиза → письма и лендинг.
10. **Paywall/подписка/письма/dunning** (эти суммы и тексты — из макетов «Оплата и письма»).
11. **Края**: пустые, офлайн/онлайн, страж в моменте, push-правила.
12. **Лендинг** (гостевой web).
