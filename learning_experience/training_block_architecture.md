# Архитектура тренировочных блоков

Дата: 2026-07-13 · (PHASE 5) Тренируем БЛОКАМИ, не разрозненными упражнениями. Избегаем монокультуры: разные объекты требуют разной архитектуры.

## Иерархия
1. **микро-действие** (тап, выбор, произнести) →
2. **упражнение** (cloze, shadowing, «скажи через X») →
3. **тренировочный блок** (связка упражнений под ОДИН тип объекта/навык) →
4. **дневной цикл** (1–2 блока + вход + вывод + возврат) →
5. **недельный цикл** (баланс блоков + deep-work + live) →
6. **учебная стадия** (S0–S4).

## Принцип против монокультуры [A]
Грам-конструкция (процедурализация через употребление), произносительный контраст (перцепция→артикуляция) и дискурс-стратегия (только во взаимодействии) — **разные архитектуры**, не один шаблон. Дневной цикл собирает 1–2 блока под узкое место дня, не «все подряд».
