## Честная правда про стадию

**A/B-тесты сейчас технически невозможны.** Чтобы поймать даже +20% при базовой конверсии 10%, нужно ~3000 человек на вариант (таблица размеров выборки). Пользователей — Галина + единичные тестеры. Классический A/B на этой стадии = самообман.

**Что реально работает сейчас:**
1. **Качественные тесты** — 5–10 живых человек, наблюдение, где путаются. Первый такой тест уже прошёл: Галина не поняла роли → экран переработан (онбординг + 2 режима, коммит 502089b).
2. **Инфраструктура для будущего A/B** — заложить флаги и трекинг событий сейчас (частично есть: журнал событий `ie_events`, эмиссия `word-noticed`/`checkin-interest` для замера).
3. **ICE-приоритизация** вместо гадания.

**Когда включать настоящий A/B:** после ~200+ активных пользователей (тогда хватит на бинарные метрики вроде completion онбординга). До этого — качественные интервью + метрики удержания на своей когорте.

## Готовые к запуску A/B (когда будет трафик)

### E6 — Output-слой (приоритет №1 аудита)
```
Because рецептивно-продуктивный разрыв закрывается только производством (наука, Strong),
we believe добавление вечернего статуса + голоса к входу+SRS
will cause больший прирост речи и completion,
for взрослых B1–B2 «понимаю, но не говорю».
We'll know when: внешний speaking-срез до/после (дельта B > контроля) и completion ≥60%.
```
- **Вариант A (контроль):** вход + SRS + узнавание.
- **Вариант B:** то же + карточка «Статус дня» + запись голоса + «Скажи сама».
- **Primary:** дельта self-rated speaking + 2-мин срез (уже есть /checkup).
- **Guardrail:** completion дня не падает; трение не растёт.
- **Инфраструктура:** нужна когорта 40–60 чел (из аудита MVP-A).

### E7 — Цель-first онбординг
- **A:** старый онбординг (уровень/темы/слова). **B:** цель-first (жизненная цель → часы → способности) — **уже дефолт**.
- Для честного теста нужен флаг, откатывающий на старый порядок. **Not built** — заложить при появлении трафика.
- **Primary:** completion онбординга + retention недели 1.

## Что ещё нужно (не A/B — продукт)

1. **Контент-пайплайн** (главное по объёму): роли из Gutenberg-диалогов, частотный словарь, больше блоков. Разово тяжело — потом растёт сам.
2. **Флаг-инфраструктура** для будущих A/B (простой feature-flag модуль поверх prefs/событий).
3. **Аналитика** — сейчас событий-журнал есть, но нет дашборда. При деплое — подключить (PostHog free tier или свой на sync_events).
4. **Реальные пользователи** — без них весь A/B-блок остаётся теорией. Приоритет: 10–20 живых тестеров для качественных тестов.
