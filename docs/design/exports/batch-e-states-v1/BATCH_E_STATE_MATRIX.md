# BATCH E · STATES V1 · МАТРИЦА СОСТОЯНИЙ

База: замороженные defaults `batch-e-correction-v1` (не перерисованы). Лист = отдельный phone-кадр на борде и файл в `screens/`.

## S19 Библиотека
| Состояние | Лист | Заметки |
|---|---|---|
| default с материалами | замороженный default (correction-v1) | без изменений, на борде состояний не дублируется |
| пустая библиотека | S19_empty | приглашение без вины; поиск доступен |
| поисковый запрос / результаты | S19_search_results | результаты — тихие карточки; путь не двигается |
| нет результатов | S19_search_empty | честно + выход «Показать весь каталог» |
| загрузка (поиск) | S19_search_loading | скелетоны; неблокирующий поиск |
| импорт-карточка future/disabled | внутри default и S19_empty | «скоро · Пока недоступно.»; тап не создаёт событий |
| материал недоступен / сеть | S19_unavailable | «Сеть не отвечает» + пилюля «недоступен»; retry-кнопка |

## S21 Материал (слушать/читать)
| Состояние | Лист | Заметки |
|---|---|---|
| default из библиотеки (фраза выбрана) | замороженный default | покрывает «selected phrase» |
| загрузка материала | S21_loading | скелетоны, честная строка «Загружаем материал…» |
| аудио недоступно | S21_audio_unavailable | текст живёт, учебный запуск сохранён |
| текста нет | S21_transcript_unavailable | слушание живёт; «взять фразу» честно отключено |
| фраза не выбрана | S21_no_selection | терракота в спокойном (disabled) виде + подсказка |
| возврат к источнику | свойство всех листов | «‹» → источник; строка внизу default |
| Path-вариант (шаг дня) | PLANNED — не спроектирован | отличие: адрес возврата и нижняя строка; ждёт решения владельца |

## S22 Повторение за голосом
| Состояние | Лист | Заметки |
|---|---|---|
| доступно / default | замороженный default | гейт-факт «Смысл уже разобран» |
| гейт: смысл не разобран | S22_locked_meaning | planned insufficient-состояние; путь к материалу; записи нет |
| запрос доступа к микрофону | S22_permission_request | честно: зачем и где остаётся запись |
| доступ не разрешён | S22_permission_denied | без вины; всё остальное доступно; «как включить» |
| идёт запись | S22_recording | один контрол: стоп + таймер; без красного |
| записано | S22_recorded | оставить / ещё раз / удалить |
| переслушивание | S22_playback | сравнение — её выбор, не задание |
| повторная запись (retry) | внутри S22_recorded | кнопка «Записать ещё раз» |
| не сохранилось (место) | S22_save_failed | роза-поправка; запись не потеряна |
| приватность видима | все листы | карточка приватности присутствует везде |
| нет оценки голоса/произношения/акцента | инвариант | ни в одном состоянии нет баллов, красного, суждений |
