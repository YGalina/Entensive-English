Гейт — planned

S22 spec · правило не ратифицировано
Голос без оценки
Во всех состояниях записи нет баллов, красного и суждений об акценте; сравнение с оригиналом — её выбор. Lifecycle записи — как в замороженном S5.
S22 spec · приватный артефакт
Честные недоступности
Сеть, аудио, текст, место на телефоне — разные честные состояния; ничего не «синхронизируется в облаке», данные не теряются молча.
Data truth · без выдуманных процессов
Латеральность
Все состояния сохраняют возврат «‹» к источнику; ни поиск, ни просмотр, ни запись не создают прогресс-событий. Path-вариант S21 — planned, не спроектирован.
