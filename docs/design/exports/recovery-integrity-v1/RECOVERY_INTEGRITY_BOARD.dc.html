S1 · КАРТА СОСТОЯНИЙ ЦЕЛОСТНОСТИ
D1 · Обнаружение и блок
Запуск обнаруживает повреждение без подтверждённого источника восстановления → прежний путь блокируется до явного решения. Тихий new-user flow исключён.
§04.17 · S1 граничный случай
D2 · Честное объяснение
Известное и неизвестное названы прямо; восстановление не обещается. Два действия: «Попробовать позже» (первичное) и «Начать заново» (второстепенное, с последствием под кнопкой).
Тон: факт, не вина
D3 · Попробовать позже
Повторная проверка по её действию: «Проверяю…» → либо путь продолжается с места, либо тот же честный экран («Пока не получилось прочитать. Можно вернуться позже.»). Ничего не теряется дополнительным ожиданием.
Ожидание — законное разрешение
D4 · Подтверждение перезапуска
Три наблюдаемых последствия названы до действия; деструктивная кнопка активна только после явного «Я понимаю»; безопасный выход «Вернуться» всегда рядом.
Случайное подтверждение исключено
D5 · Новый путь начат
После подтверждения — знакомство и стартовая проверка заново (замороженные S2→S3→S7, не перерисованы). Начало явно новое; прежнее не «продолжается» молча.
Разрешено выбором, не по умолчанию
D6 · Разрешено чтением
Если при повторной проверке записи читаются — путь продолжается с того же места без пере-подтверждений; блок снимается сам собой.
