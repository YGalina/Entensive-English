# RECOVERY · STATE MATRIX v1
## S6 Recovery поверх замороженных Batch A/C · state ID · триггер · копирайт · действия · данные · восстановление · источник

Замороженные источники: S4 — batch-a-defaults-final; фазы 3–5 и S14 — batch-c-correction-v1 + batch-c-states-correction-v1. Recovery переиспользует их состояния без изменений; ниже — только новое.

## Контракт завершения и непрерывность
| ID | Правило |
|---|---|
| RC1 | due>0: минимум = ≥1 возврат единицы И одно производство; ноль due: минимум = одно производство |
| RC2 | Safe exit ≠ completed recovery; открыть и выйти — не завершение; черновик фазы сохраняется |
| RC3 | Recovery не создаёт курс-сессий и не двигает счётчик 14; чип «Программа не расходуется» |
| RC4 | Возврат после прерывания — в точную фазу с черновиком (замороженный W6) |
| RC5 | Голос пропущен и/или разбор недоступен — recovery всё равно завершается корректно |
