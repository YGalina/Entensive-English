## Допущения (для owner/QA)
1. Порог паузы ≥2 календарных дней — каноническое runtime-правило (§04.5); экран лишь отражает сигнал.
2. Главный вопрос производства — из курируемого банка; строка на борде иллюстративная.
3. «до 8 знакомых фраз» в чипе показывает верхнюю границу; фактическое число — по due на день.
4. Тихий счётчик «2 из 6» — ориентир объёма возврата; не оценка и не стрик.
5. Деструктивное подтверждение — галочка-подтверждение + кнопка; press-and-hold не вводился (нет прецедента в системе).
6. D6 «разрешено чтением» показывает замороженный S1-вход; отдельный экран не нужен.
