## Гендерная заметка
«Узнаешь их сама» нейтрализована в correction v1 («…и уже будут знакомы»). Оставшееся «чем я думала» — речь персонажа в переводе примера, допустимо.

## Firewall
Ноль вхождений: пилот · срез · протокол · SRS · DLE · retrieval depth · shadow · core · state-имена · S-номера. «Проверить» — учебный режим (лесенка+ретрай легальны), не оценка.
