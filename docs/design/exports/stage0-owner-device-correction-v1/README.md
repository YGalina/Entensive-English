# Stage 0 · Owner device correction v1

Коррекция по обратной связи владельца с физического Android-устройства. Четыре группы, 15 отдельных экранных экспортов, одна доска обзора.

- `REVIEW_BOARD.html` — доска обзора (самодостаточный файл, работает офлайн).
- `screens/` — отдельные экранные экспорты.
- `COPY_AND_STATE_INVENTORY.md` — инвентарь состояний и строк с указанием источника.
- `IMPLEMENTATION_HANDOFF.md` — аннотации по viewport'ам и поведению клавиатуры.
- `CODEX_QA_PACKAGE.md` — пакет на проверку готовности к реализации: дельта к Developer Handoff v3, критерии приёмки, матрица устройств, регрессии, firewall.

Группы:

1. Завершение стартовой точки — 2 экрана (390, 360).
2. Клавиатура открыта — 6 экранов: извлечение, свободный вывод, управляемая вариация × 360 и 390.
3. Реальный отклик после вывода S14 — 4 состояния: A выполнено · B по теме без рамки · C мягкая самопроверка · D разбор не получился.
4. Три равных ответа S3 — 3 экрана: 100 %, 200 %, 200 % прокручено.

Ни один принятый экспорт не изменён. Прикладного кода нет. Остановка для визуального утверждения владельцем.
