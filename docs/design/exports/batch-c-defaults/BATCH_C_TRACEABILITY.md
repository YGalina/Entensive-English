## Претест-защита
Иллюстративные единицы Batch C (that makes sense / I’ll get back to you / it’s up to you) и фраза производства (kitchen renovation…) обязаны не входить в 28 оценочных фраз, не быть их парафразом/near-transfer вариантом и не тренировать оцениваемую конструкцию до базовой линии — требование к подбору реального контента (пункт QA-чеклиста, как в Batch A/B).
