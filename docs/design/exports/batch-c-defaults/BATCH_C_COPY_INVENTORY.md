## Гендерная заметка
Обращение гендерно-нейтральное, кроме двух строк с «узнаешь их сама» и «чем я думала» (перевод примера — речь персонажа, допустимо). «Узнаешь их сама» — кандидат на нейтрализацию: «узнаются сами» (вопрос владельцу №4).

## Firewall
Ноль вхождений: пилот · срез · протокол · SRS · DLE · retrieval depth · shadow · core · state-имена · S-номера. «Проверить» — учебный режим (лесенка+ретрай легальны), не оценка.
