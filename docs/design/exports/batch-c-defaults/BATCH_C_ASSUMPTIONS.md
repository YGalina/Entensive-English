# BATCH C · ASSUMPTIONS AND OWNER DECISIONS

1. **Имена фаз learner-facing:** Прайминг/Встреча/Извлечение/Производство — внутренние; на экранах только счётчик «n из 6» и естественные заголовки («Три фразы на сегодня», «Текст дня», «Вспомни и напиши», «Своя фраза»). Подтвердить.
2. **«Проверить» в фазе 3:** учебный режим допускает проверку с лесенкой и ретраем; кнопка disabled до ввода, отдельной «Не помню» нет — её роль выполняет лесенка (буква → выбор → показ). Если владелец хочет «Не помню» и здесь — добавлю в state-фазе.
3. **Терракота в сессии:** «Дальше/Готово/Продолжить путь» — терракота #C94E2D как действие пути (учебный режим); внутри извлечения активная «Проверить» будет чернилами (граница с оценочным сохранится визуально мягче). Альтернатива — терракота и там; жду решения.
4. **Гендер:** «узнаешь их сама» — женское обращение (ЦА и тон Галины), но правило gender-neutral формально требует «узнаются сами». Выбрать.
5. **Focus-охват:** показана одна фаза (извлечение) как proof направления; остальные фазы Focus — после одобрения, тем же скином.
6. **Признание в S14:** «Фраза сказана. Твоя.» — по фактической модальности (написана+возможно произнесена). Если строго письменная: «Фраза написана. Твоя.»
7. **Иллюстративный контент** (3 единицы, текст дня, фраза о ремонте) — placeholder; реальные единицы дня приходят из учебной программы с обязательной проверкой непересечения с 28 оценочными (см. TRACEABILITY).
8. **Safe exit:** «‹» выходит с сохранением черновика; на default не показан confirm — прерывание/возобновление в state-фазе.
