# Path Hub · шапка карточки недели · коррекция по устройству v1

Статус: **на визуальное утверждение владельца.** Код приложения — вне области Fable.

## Свидетельство

Физическое Android-устройство, Expo Go, 05.08.2026 10:45. Path Hub — верная продуктовая поверхность. Дефект локализован в шапке карточки недельной практики: `ВРЕМЯ ПРАКТИКИ · АВГУСТ` и `Первая неделя` стоят вплотную (видимая строка `АВГУСТПервая неделя`) и обрезаются у правого края карточки.

## Причина

Шапка собрана как один негибкий ряд: левая метка не сжимается и не переносится, правая прижата `marginLeft: "auto"`, переноса у ряда нет. Русское полное название месяца в верхнем регистре с трекингом .6 при ширине контента 272 dp (360 dp − 26 × 2 отступа экрана − 18 × 2 паддинга карточки) шире доступного места, поэтому вторая метка выдавливается за границу.

## Правка

Шапка становится **одним переносящимся рядом**:

- контейнер: `flexDirection: "row"`, `flexWrap: "wrap"`, `alignItems: "baseline"`, `justifyContent: "space-between"`, `columnGap: 12`, `rowGap: 4` (при крупном системном тексте 6);
- левая группа «точка + месяц»: `flex: 1 1 auto`, `minWidth: 0`, перенос по словам разрешён; `marginLeft: "auto"` у правой метки удаляется;
- правая метка `Первая неделя`: `flexShrink: 0` — не сжимается, при недостатке ширины уходит на вторую строку ряда и выравнивается по левому краю;
- никакого `numberOfLines`, `ellipsizeMode`, `nowrap`, сокращения текста и уменьшения кегля.

Оба факта — месяц и `Первая неделя` — остаются на экране всегда.

## Неизменное

Иерархия и цвета: месяц #6F6857, `Первая неделя` тише — #B0A893, точка #4FB286. Шапка остаётся служебной подписью и не спорит с ведущим шагом выше. Ряд семи дней, подпись `Часы появятся после первой сессии.`, карточка первой практики, карточка библиотеки, навигация и механика — без изменений.

Не восстанавливается: прежний онбординг, стрики, стражи, levelcheck, музыка, апселл коуча, автопрокрутка слов.
