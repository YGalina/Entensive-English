## Непрерывность сессии
| ID | Правило |
|---|---|
| C1 | Частичная сессия: выход в любой фазе сохраняет черновик фазы; не провал |
| C2 | Safe exit ≠ session-completed; счётчик 14 не двигается |
| C3 | Возврат — в точную фазу с черновиком |
| C4 | session-completed — только ≥1 извлечение И одно производство (ядро) |
| C5 | Голос пропущен и/или разбор недоступен — сессия всё равно завершается корректно |
