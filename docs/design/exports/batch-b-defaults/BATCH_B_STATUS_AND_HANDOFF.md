## Визуальная преемственность
Оценочный режим S7 продолжен без изменений: прогресс чернилами на wash, поле с autocorrect off, «Не помню» первого класса, «Дальше» disabled до ввода, ноль цвета успеха/наград/подсказок/ретраев. Активные действия в оценочном режиме — чернила #22201B («Отправить» в S10). Терракота возвращается только на действиях пути после оценивания (S12 «Завершить проверку», S13 «Поделиться результатами»). Мята в S12/S13 — только полнота частей (факт состояния), не качество.

## Interaction contracts
- **S9/S11:** как S7 — submit-lock на время записи; двойной тап отклоняется ядром и показывается нейтрально «уже записано»; возобновление пропускает записанные; завершение по полноте (22 / 6) однократно. Порядок фраз — ядро; UI не сообщает происхождение фраз.
- **S10:** единственная отправка; input-gate — только «непустой ответ ≥10 символов» (короткий валидный ответ = завершённый; 25-словная классификация — внутренняя, в UI не появляется). Голос: full lifecycle как в учебной сессии (permission/recording/interrupted/empty/storage/playback); любой сбой → письменный поток без потери; голос не блокирует «Отправить». Отправка строго до S11.
- **S12:** доступен только при полноте всех трёх частей (ядро отклоняет ранний вход — состояние в state-фазе); действие однократно; повтор отклоняется; не переписывает ответы.
- **S13:** достижим только после закрытия; «Поделиться результатами» открывает системный share-sheet; повторные отправки — чистое чтение, без новых событий. Состав файла в UI описан по-человечески; техструктура не показывается.
- Тач-цели: все действия 56px; голос-кнопка 44px+; «К практике» hit-зона ≥44px. Pressed scale .98; focus-visible 2px #E8623D offset 2; disabled wash/#6F6857 + aria-disabled; прогрессы role="progressbar".
