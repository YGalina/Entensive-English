# BATCH E · CORRECTION V1 · КОПИ-ИНВЕНТАРЬ

## Что изменено в correction v1
- S22 гейт: «Материал понятен / Ты уже разбирала эти фразы — можно повторять вслух.» → «Смысл уже разобран / Теперь можно повторить фразу вслух.» (без ложного оценочного заявления).
- S22 запись: иконка и ярлык объединены в одну кнопку-пилюлю; текст «Записать свой повтор» — видимый ярлык и accessible label (aria-label).
- S19 импорт: карточка «Переведи свою жизнь» приглушена (disabled), добавлено «Пока недоступно.»
