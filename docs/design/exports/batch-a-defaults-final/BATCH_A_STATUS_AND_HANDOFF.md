## Решения новых экранов
- **S1:** «свет лампы» сохранён (короткий переход, не лендинг); статус «Открываем твой следующий шаг…» — человеческий язык маршрутизации; без цитат, Галины, объяснений продукта.
- **S7:** заголовок «Что вспоминается сейчас»; метка «НАПИШИ ПО-АНГЛИЙСКИ»; default-элемент = прогресс (3 из 28, чернила на wash) · русская фраза · поле ответа (placeholder «Ответ по-английски», autocorrect off, фокус) · два равноправных действия «Не помню» / «Дальше» (Дальше — disabled + aria-disabled до непустого ввода; активное состояние — чернила, не терракота/мята). Клавиатура показана как реальное состояние ввода — функциональная плотность без театра. Эмоциональный контракт — только в интро-состоянии (state-фаза). Ноль цвета успеха, подсказок, ретраев, таймеров, обещаний о будущих фразах.
- **S8:** заголовок «Следующая проверка», связка «Откроется после 14 сессий, но не раньше 26 июля.»; два условия читаются полосами до текста (мята = сессии 11 из 14, латунь = «Прошло дней» 8 из 14), остатки («осталось 3 сессии / 6 дней») и точная дата в пилюле; одно действие «Вернуться к практике». Без «второго фото», гейтов, наказания, стриков, выдуманной программы.

## Pretest protection (в handoff)
Иллюстративные фразы до S7 и в примерах: S2 “So… what do you think?” / “Well, I”, S3 “We met the deadline.” — (а) не входят в 28 оценочных фраз, (б) не парафраз/near-transfer их вариантов, (в) не оцениваются, (г) не тренируют оцениваемую конструкцию. Фраза в макете S7 «Я постепенно к этому привыкаю.» — иллюстративная; реальные 28 берутся из учебной программы при имплементации. Проверка непересечения — обязательный пункт QA-чеклиста.

## Interaction / accessibility handoff (сводно)
- Тач-цели: «Прослушать» 44px+ · back «‹» 44×44 · «‹ Предыдущий ответ» hit-зона ≥44px · строка «Библиотека» ~72px · CTA 56px · ответы S3 60px · «Не помню»/«Дальше» S7 56px · «Вернуться к практике» 56px.
- Состояния: pressed scale .98 + wash; focus-visible 2px #E8623D offset 2; disabled — wash/#6F6857 + aria-disabled; submit-lock в S7 блокирует оба действия на время записи (идемпотентность ядра).
- Прогрессы: role="progressbar" (S3 3/5, S7 3/28); полосы S8 role="img" с aria-label «Сессии: 11 из 14» / «Дни: 8 из 14».
- Поле S7: autocorrect/autocapitalize/spellcheck off; «Автоисправление выключено» через aria-describedby; клавиатура системная (в макете — иллюстрация состояния).
- prefers-reduced-motion: курсоры и переходы отключаемы; body ≥16px, вторичный ≥14px; гендерно-нейтральный русский.
