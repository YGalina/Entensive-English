СИСТЕМА И ПЕРЕИСПОЛЬЗОВАНИЕ
Латеральность
Все четыре экрана — кладовые: вход из тихой периферии Path Hub, «‹» → источник входа; просмотр не двигает путь и не создаёт прогресс-событий.
§05.1 · IA: латеральное ≠ продвижение
Семантика статусов слов
Новое — амбер · знакомое — мята · ждёт повторения — терракотовая точка. Везде точка + слово; цвет — только ориентация.
DS Living Content · без красного
Повторение = фаза 3
После «Начать повторение» — замороженный скаффолд извлечения (R1–R7 из batch-c-states-correction-v1) без изменений; здесь спроектирован только вход.
Переиспользование; не перерисовано
Holdout-фильтр
Контрольные единицы не проявляются в «Мои слова», поиске и повторении до разрешённого этапа — свойство данных, в UI не упоминается.
