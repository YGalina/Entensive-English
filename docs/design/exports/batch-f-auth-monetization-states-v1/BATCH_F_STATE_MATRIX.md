## Инварианты всех листов
Ошибки — роза #C75A7A (поправка), недоступности — чернила на wash #EFE7D7, успехи — мята без конфетти. Отказ/бесплатный режим всегда видимы. Нет таймеров, дефицита, «мы скучаем», удержаний. Деньги не списываются молча; локальные данные не перезаписываются и остаются её.
