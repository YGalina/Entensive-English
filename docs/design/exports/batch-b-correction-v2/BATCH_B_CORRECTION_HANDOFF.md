## Изменено визуально
1. **Контраст (S9–S13):** активные CTA #E8623D → #C94E2D (белый текст 3.4→4.6:1); плейсхолдеры #B0A893 → #6F6857 (2.4→5.5:1); синий текст счётчиков #4A7BA6 → #3E6A8F (4.2→5.3:1). #4A7BA6 сохранён для нетекста: прогресс-полоса, рамка фокуса, маркеры (4.2:1 ≥ 3:1). #E8623D сохранён для нетекстовых акцентов.
2. **S10:** «Отправить» в default (пустое поле) — disabled + aria-disabled, wash/#6F6857. Активируется при ≥10 непробельных символов. Подсказка «Для отправки — хотя бы несколько слов.» появляется с первого символа, нейтральная, без красного. Числового таймаута нет — ожидание до результата системной операции.
3. **S12:** повторы необратимости сведены к одному предупреждению: «Ответы уже сохранены — изменить их нельзя. Закрытие подводит итог, один раз.» Подзаголовок сокращён. Список трёх частей и CTA «Завершить проверку» сохранены.
4. **S13 (v2):** «Голосовые записи — ссылки без аудиофайлов» + пояснение «Сами записи остаются на этом устройстве и не передаются.» (решение B по реализации). «Повторная отправка…» → «Повторное открытие меню „Поделиться“ не меняет результаты.» Статус «Отправлено» исключён; «Передано в выбранное приложение» — только при достоверном системном сигнале; отмена — без статуса.

## Изменено только в annotations/handoff
- Семантика цвета согласована: **терракота #C94E2D = первичное действие пути** (S10 «Отправить», S12 «Завершить проверку», S13 «Поделиться результатами»), не правильность/успех/награда; **чернила #22201B = активные действия внутри оценочных элементов** (S9/S11 «Дальше», «Повторить»). Прежняя формулировка «оценочные действия — ink» относилась к элементам среза S9/S11 и не запрещает терракоту в S10: «Отправить» — явная отправка завершённого ответа, allowed. Конфликт снят; подтверждение — вопрос владельцу №3.
- Интерактивные контракты: progressbar-роли, реальные input/textarea, голосовая кнопка с accessible name, «К практике» ≥44px — см. ACCESSIBILITY_CONTRACT.
- Голосовые состояния: формулировка «записалось только молчание» исключена; используются технически наблюдаемые «Запись не сохранилась» / «В записи нет доступного аудио».
