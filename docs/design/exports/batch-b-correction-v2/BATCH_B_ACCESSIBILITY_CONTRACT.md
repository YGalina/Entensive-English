# BATCH B · ACCESSIBILITY CONTRACT
## S9–S13 · обязательные контракты реализации

## Роли и имена
- Прогресс S9/S11: `role="progressbar"`, `aria-valuenow`/`aria-valuemax`, accessible name «Проверка: фраза 5 из 22» (без research-слов).
- Поля S9/S11 — реальные `<input type="text">`; S10 — `<textarea>`; `autocorrect="off" autocapitalize="off" spellcheck="false"`; «Автоисправление выключено» связано через `aria-describedby`.
- Голосовая зона S10 — настоящая `<button>` c accessible name «Записать голосом — по желанию»; состояния записи объявляются (`aria-pressed`/live region).
- «К практике» (S13) — интерактивный элемент (link/button), hit area ≥44×44 за счёт padding.
- Строки-части S12 — не интерактивны в ready-состоянии; в unavailable-состоянии незавершённая часть — ссылка «продолжить».

## Disabled vs aria-disabled
- «Дальше» (S9/S11) и «Отправить» (S10) до валидного ввода: атрибут `disabled` + `aria-disabled="true"`; элемент остаётся в DOM и объявляет причину через `aria-describedby` («Сначала напиши ответ» / «Для отправки — хотя бы несколько слов»).
- В submitting-lock: `aria-disabled="true"` без удаления фокуса; фокус не теряется после разблокировки.

## Объявления
- Loading: `aria-live="polite"` «Отправляю…» / «Закрываю…» / «Открываю…».
- Ошибки: `role="alert"` — «Не записалось…», «Не отправилось…», «Не получилось закрыть проверку…», «Не получилось подготовить файл…». Текст ошибки называет, что случилось и что можно сделать.
- Принятие ответа — без объявления оценки; только смена позиции прогресса.

## Сохранность ввода
Текст никогда не очищается: при сбое, блокировке, повороте, возврате из share sheet, прерывании записи. Дубликаты предотвращаются идемпотентным submit (повторный тап/клик игнорируется до результата).

## Focus и клавиатура
- Reading order = DOM: заголовок → прогресс → фраза/задача → поле → подпись → действия.
- Keyboard focus order — только интерактивные: поле → «Не помню» → «Дальше» (S9/S11); поле → голос → «Отправить» (S10); CTA (S12); «Поделиться…» → «К практике» (S13). Декоративные блоки вне tab-порядка.
- `focus-visible`: 2px #C94E2D (на светлом) offset 2px; на синей рамке фокуса поля — двойная граница (#4A7BA6 + внешний #22201B 1px), не только цвет.
- Экранная клавиатура не перекрывает действия: S9/S11 — действия закреплены над клавиатурой; S10 — «Отправить» достижима прокруткой, окно прокручивается к фокусу.

## Не только цвет
Каждое состояние имеет форму/текст: disabled — заливка wash + атрибут; фокус поля — рамка 1.5px + каретка; ошибка — панель с текстом; принято — смена контента и счётчика; запись — таймер + подпись.

## Reduced motion
`prefers-reduced-motion`: без переходов между фразами, без пульса записи (статичная точка + таймер), без каретки-анимации.

## Контраст
См. таблицу в CORRECTION_HANDOFF: все текстовые сочетания ≥4.5:1; крупный/нетекст ≥3:1; disabled — исключение AA, но различим.

## Touch targets
Все интерактивные ≥44×44: CTA 56px; «Не помню»/«Дальше» 56px; голос 44px; «К практике» ≥44px hit; back/системные жесты — платформенные.
