Граничные состояния
ПРЯМОЙ ЗАХОД ПО ССЫЛКЕ / УВЕДОМЛЕНИЮ
Любая попытка открыть тест раньше guard ловится ядром и показывает этот же экран — состояние одно, откуда бы ни пришли. Stale-уведомление ведёт в актуальный Path, не в сохранённую цель.
ЗАГРУЗКА ГАРДА
Пока ядро считает условия — тёплые плейсхолдеры; цифры не мигают и не «дорисовываются» с нуля.
СВЯЗЬ С S4
S8 — информационная страница «почему закрыто». Действие ожидания живёт на тропе (1b, окно ожидания): здесь нет второго CTA — только «Вернуться к тропе».
АННОТАЦИИ · S8 → СПЕКА 06 §E
Тон: «закрыт — и это правильно»: причина — метод, не замок и не наказание. Ни guilt, ни «поторопись».

Два условия — две полосы: сессии (терракота) и дни (латунь) визуально разные оси; выполненное условие получает мятный тик, невыполненное — спокойный факт «день 11 из 14», не тревожный таймер.

Дата открытия всегда названа конкретно («2 августа») — обещание проверяемо.

Один выход: ghost-кнопка «Вернуться к тропе»; никаких конкурирующих CTA — ведущий шаг ожидания живёт в S4.

Без записи: экран информационный, событий аналитики не создаёт.
