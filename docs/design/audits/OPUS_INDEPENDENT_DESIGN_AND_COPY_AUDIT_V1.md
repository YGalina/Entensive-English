## 2. Executive verdict

1. **Существующий визуальный продукт спасаем?** Да. Визуальный язык Living Content — бумага/чернила, Golos/Lora, амбер=новое/мята=знакомое, терракотовый единственный CTA, честные часы, focus «свет лампы» — выражает утверждённый продукт лучше, чем любой из известных альтернативных стилей, и уже несёт ключевые ценности (тишина, достоинство взрослого, честность). Проблема не в стиле, а в том, что часть экранов рисовалась под **прежнюю модель продукта** (CEFR-самооценка, стражи, стрики, каталог навыков, Галина внутри приложения, word-flood с «Знаю»).
2. **Living Content уместен?** Да, без замены. Токены `packages/tokens/index.ts` — канон; правки только семантические (deprecated-метка стражей, семейства «оценочный режим» и S27).
3. **Процент переиспользования (расчёт явный, знаменатель 55 slices-v2):** KEEP 4/55 = 7% · ADAPT 25/55 = 45% · REBUILD 2/55 = 4% · ARCHIVE 9/55 = 16% · FUTURE REFERENCE 15/55 = 27%. **Переиспользуемо сейчас (KEEP+ADAPT): 29/55 = 53%.** С учётом будущих поверхностей (＋FUTURE REF): 44/55 = 80%. Визуальный вердикт «✓ канон» у 51/55 ≈ 93% — визуальный язык переиспользуется почти полностью даже там, где механика устарела. Legacy `screens/` (29 файлов): 25 ARCHIVE · 4 FUTURE REFERENCE.
4. **Сильнейшее:** mobile 02 «Сегодня» (ведущая карточка + честные часы «Пауза, не потеря») · mobile 04 «Контекст» · mobile 22 / web 13 «Читалка» · focus 01 визуально · mobile 32 (офлайн-честность) · mobile 35 (тон клуба) · mobile 28/29 (честная оплата) · большой корпус честного копирайта (§8).
5. **Носители устаревшей логики:** mobile 06 / web 06 «Прогресс» («86 ч из ~200 до B2», «28 подряд», стражи, психометрия чувств) · mobile 30 + legacy levelcheck* (CEFR-самооценка) · mobile 20/33 и строки стража в 06/07/26/27, web 05/06, focus 02 · mobile 31 / web 01/02 (Галина в приложении) · mobile 03 / focus 01 (word flood + «Знаю») · mobile 21 / web 05 (каталог «Навыки») · legacy flow.html (когортные «потоки»).
6. **Готов ли проект к системному визуальному редизайну?** Да — при трёх условиях: (а) Batch 1 используется только как перечень состояний, не как визуальный или **копирайт**-источник (в нём — системная утечка внутренней терминологии, см. Finding F-1); (б) первый батч = связный journey Batch A на implementation-вьюпорте 390×844; (в) решения владельца §11 приняты до соответствующих батчей.

## 3. Findings (Critical / Major / Minor)

Формат: серьёзность · экран/путь · управляющий источник · текущее · проблема · эффект на опыт · эффект на обучение · что сохранить · минимальная правка · классификация · уверенность.

### F-1 · CRITICAL · Утечка внутренней терминологии в learner-facing копирайте Batch 1
- **Экран:** `docs/design/project/batches/Intensive English - Batch 1 (S3 S4 S7 S8).dc.html` — внутри телефонных рамок (не в аннотациях): заголовок «Вход в пилот», CTA «Сохранить и войти в пилот», «Данные пилота хранятся только на этом устройстве и выгружаются вручную с экрана пилота», бейдж «Пилот · Vertical Slice» в шапке хаба (заявлен в артефакте как намеренный).
- **Источник:** D-04 «User-facing language firewall»: pilot / vertical slice / protocol / core-accepted / S-идентификаторы — internal-only; «`PILOT · VERTICAL SLICE` must never appear as a learner-facing badge».
- **Проблема:** язык спецификации подан как язык интерфейса. Учащаяся читает о себе «пилот», «данные пилота», «выгрузка» — рамка эксперимента вместо рамки обучения.
- **Опыт:** взрослая учащаяся становится «испытуемой»; достоинство и эмоциональный контракт («стартовое фото», «твоя практика») ломаются.
- **Обучение:** research-рамка усиливает оценочную тревогу — прямо против цели протокола (спокойные, валидные свидетельства).
- **Сохранить:** инвентарь состояний Batch 1 (S27, идемпотентность, «не помню» как равноправная кнопка) — он ценен.
- **Минимальная правка:** исследовательская рамка живёт только на отдельной поверхности информированного согласия / информации о программе (S3 заполняется вместе с Галиной — это легитимное место для объяснения исследования). На S4/S7/S8 и любых рутинных экранах — язык обучения: «Твоя программа», «Стартовое фото», «Мои данные». Реестр замен — §7.
- **Классификация:** Batch 1 → FUTURE REFERENCE (только состояния). **Уверенность: высокая** (текст извлечён из артефакта).

### F-2 · CRITICAL · «Прогресс» обещает уровень и считает чувства
- **Экран:** `slices-v2/mobile/06_5__ПРОГРЕСС.html`, `slices-v2/web/06_ПРОГРЕСС.html`.
- **Источник:** Конституция §3 (уровень — только из внешне-валидного среза; без психологической интерпретации), progress_and_assessment_model_v2 (CEFR «НИКОГДА из активности»), progress_experience (без «подряд»).
- **Текущее (проверено):** «86 ч из ~200 до B2» · «Записать статус дня голосом · 28 подряд» / «28 дней подряд» · «Чаще всего приходит страх ошибки. Ты давала ему место 9 раз — и 7 раз потом говорила» · дорожки с ярлыком «B1+».
- **Проблема:** три запрещённых класса заявлений на одном экране: CEFR из активности, стрик, психологическая интерпретация с **количественным учётом чувств** (счётчик «9 раз») — последнее жёстче, чем зафиксированный в D-02 «страж как факт пути»: это метрика аффекта.
- **Опыт:** ложное обещание срока → неизбежное разочарование; стрик → вина за разрыв; счёт чувств → слежка вместо поддержки.
- **Обучение:** активность выдаётся за компетенцию; внутренние состояния — за данные.
- **Сохранить:** иерархию «Что я теперь могу» сверху, чек-лист способностей («Понять 6-минутное видео без субтитров»), «Рассказать о работе 2 минуты · держу 1:20» (класс task performance — легален), «Слух впереди речи — нормальный разрыв», тихие полосы, мятные тики.
- **Минимальная правка:** REBUILD: заявления только по классу свидетельства; часы — ориентир без «до B2»; убрать «подряд» и весь блок чувств; письменное ≠ устное.
- **Классификация:** REBUILD IN LIVING CONTENT (оба). **Уверенность: высокая.**

### F-3 · CRITICAL · CEFR-самооценка как вход в продукт
- **Экраны:** `mobile/19_ОНБ_3__ВРЕМЯ__УРОВЕНЬ.html` (выбор A1/B1/B2), `mobile/30_ПРОВЕРКА_УРОВНЯ.html` («Пропустить — начну с B1», результат «Ты в зоне B1» в legacy), legacy `levelcheck.html`, `levelcheck-v2.html`.
- **Источник:** Г-1 (вход = пять наблюдаемых признаков, не уровень), Конституция §3.
- **Проблема:** самовыбор уровня и 3-минутная проверка выдают CEFR-позицию из внутренней активности/самоотчёта; замещены S3 + внешне-валидным срезом S7–S13.
- **Сохранить:** копирайт «Не экзамен, а настройка», «"Не знаю" — нормальный ответ», «Без обратного отсчёта и давления», «Считаем настоящие часы, не стрики»; пилюли-выбор.
- **Минимальная правка:** ARCHIVE поверхностей; фразы — в библиотеку копирайта (§8).
- **Классификация:** ARCHIVE (m19, m30, legacy levelcheck*). **Уверенность: высокая.**

### F-4 · MAJOR · Стражи/психоинтерпретация шире, чем помечено в D-02
- **Экраны:** помимо известных m20/m33/web05/web06 — `mobile/07_6__ВЕЧЕРНИЙ_КРУГ_FOCUS.html` («Приходило высмеивание. И ты всё равно записала фразу. Ты его прошла»), `focus/02_ВЕЧЕРНИЙ_КРУГ__WEB.html` («Сегодня приходило запугивание перед клубом»), `mobile/26_ПИСЬМО.html» («Перфекционизм рядом…»), `mobile/27_РЕЧЬ__ВИДЕО.html` («Голос дрожит? Это высмеивание рядом»).
- **Источник:** Г-3, Конституция §3 (без психологической диагностики/интерпретации), psychological_coaching_boundaries_v2.
- **Проблема:** интерфейс утверждает, **какое чувство пришло к человеку**, — интерпретация, а не поддержка. D-02 пометил в Вечернем круге только стрик (К-Б); строки-интерпретации — дополнительный конфликт К-В в обоих источниках Вечернего круга и в двух мастерских. Любая будущая работа над этими поверхностями обязана убрать оба слоя.
- **Сохранить:** структуру check-in «Как ты сейчас» (самоотчёт без интерпретации — легален), «Одна фраза о дне по-английски», тихое закрытие дня.
- **Минимальная правка:** удалить интерпретирующие строки; поддержка — только фактом («Ты записала фразу. Это считается»).
- **Классификация:** m07/f02 FUTURE REFERENCE (плюс решение владельца), m26/m27 FUTURE REFERENCE с обязательной чисткой при активации. **Уверенность: высокая.**

### F-5 · MAJOR · Самозаявление как свидетельство (word flood и SRS)
- **Экраны:** `mobile/03…ПОТОК_СЛОВ.html` (кнопка «Знаю»), `focus/01…FOCUS.html` («Знаю это слово», темп «1 слово / 0,5 с»), `mobile/36_ФЛЕШ-СЛОВАРЬ_SRS.html` («Помню и могу сказать»), `web/08_СЛОВАРЬ.html` (единая шкала «новое/учу/закреплено»), `web/14_SRS-КАРТОЧКИ.html` (клейм-язык кнопок при верных интервалах).
- **Источник:** exercise_architecture_v2 (word flood → REDESIGN в прайминг 60–90 с без клеймов), шесть классов свидетельств (produce = сделала, не «могу»), конституция: раздельные recognize/produce.
- **Проблема:** узнавание + самоотчёт записываются как знание; «могу сказать» — produce-клейм без produce-события; одна шкала смешивает направления.
- **Сохранить:** карточку слова (Lora, транскрипция, пример), «Оцени честно — себе. Штрафов нет, слово просто вернётся раньше», «"Не помню" — не ошибка и не штраф».
- **Минимальная правка:** прайминг тап-послушать без задания; SRS-исходы нейтральные («вспомнила / не вспомнила»), направление карточки видимо (узнаю ↔ говорю).
- **Классификация:** ADAPT (все пять). **Уверенность: высокая.**

### F-6 · MAJOR · CEFR-ярлыки на людях и в навигации
- **Экраны:** `mobile/10` («Дмитрий · B1», «Софья · B1+»), `mobile/34` («Дмитрий B1 · Лимасол»), `mobile/38` (бейдж «B1 — и это нормально»), `mobile/11` («B1 → B2 · Лимасол»), `web/04`/`web/06`/`web/07`/`web/08`/`web/10`/`web/12` (сайдбар «Аня B1 · Лимасол»; web 10: «14 человек твоего уровня рядом»).

- **Минимальная правка:** на людях — цель/город («цель: работа · Лимасол»); в сайдбаре — имя без уровня; «твоего уровня» → «рядом с тобой».
- **Классификация:** ADAPT (11, web-сайдбар как компонент), FUTURE REFERENCE (10/34/38, web10 — при активации S24). **Уверенность: высокая.**

### F-7 · MAJOR · Доступность вторичного текста и хит-таргетов (системно)
- **Экраны:** сквозное; подписи `#9a917f`/`#b0a893` на бумаге `#F7F3EA` (контраст < AA для мелкого текста), пилюли/иконки 30–34px в ряде slices; Batch 1 — 300px-канвас с текстом 10.5–12.5px (уже отклонён).

## Copy-system recommendations

- **Голос:** взрослый, спокойный, конкретный; «ты» строчными; короткие главные предложения; факт вместо утешения; поддержка действием следующего шага.
- **Тон по контексту:** учебный режим — тёплый, с переводом рядом; оценочный — нейтрально-ровный, без подбадриваний и наград («Ответ записан»); ошибки/сбои — сначала «что с твоими данными», потом действие; напоминания — приглашение, не долг.
- **Терминология:** «сессия», «стартовое фото», «честные часы», «срез» (для даты оценки допустимо «срез/встреча со срезом» решается в Batch A-словаре), «вернуть слова»; запрещено в UI: пилот, vertical slice, протокол, гейт, trained/holdout/контрольная группа, evidence class, core-accepted, scheduler, S-номера, [IMPL]/[PLAN], DLE/SRS-внутренности (само слово «SRS» на кнопках заменять «повтором»).
- **Действия обучения:** глагол + объект («Начать сессию», «Вернуть слова», «Записать голосом», «Оставить как есть»); никакой геймификации глаголов («прокачай», «зафармь»).
- **Ошибки/восстановление:** «Не сохранилось. Всё, что ты отметила, — на экране» — канон; повтор всегда явный; «пауза, не потеря» — универсальная рамка возвращения.
- **Оценка:** «не помню» — равноправный ответ; никаких «правильно/неправильно» в срезе; не обещать, что item «придёт в сессиях».
- **Прогресс:** только «что делала» (процесс) и «что смогла» (по классу свидетельства); «данных пока мало» — легальное состояние; без «до B2», без «подряд», без процентов уровня.
- **AI:** резюме — от факта («Ты сказала…»), варианты — «ещё так говорят», всегда плашка источника; без вердиктов о человеке и без псевдоблизости.
- **Сообщество:** договорённости, а не правила-угрозы; «можно просто слушать»; отказ без объяснений.
- **Психология:** чувства может называть только сам человек (check-in-выбор); интерфейс никогда не утверждает «к тебе приходит X» и не считает чувства.
- **Нерешено (владелец):** гендерная форма обращения в русском («Согласна/Ошиблась/повторяла» — сейчас женский род по умолчанию) — §11.
