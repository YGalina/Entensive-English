## D-02 · компоненты и токены Living Content против утверждённой системы

Дата: 2026-07-19.

## 1. Канонические компоненты — KEEP
- **Ведущая карточка шага** (surface, 2px терракотовая рамка, терракотовая тень, метка-точка, один CTA) — mobile 02 / web 04. Единственный первичный элемент любого хаба. Batch 1 может использоваться только как reference по состояниям, не как визуальный канон.
- **Маркировка языка**: амбер-заливка = новое, мятное подчёркивание = знакомое; Lora для всего английского, тап-перевод. (mobile 04/22, web 13.)
- **Честные часы**: столбики месяца + подпись «Пустой день — тихий столбик. Пауза, не потеря» (mobile 02). Без «до B2».
- **Тихий факт-ряд**: 6px мятная точка + Golos 500 (slice-код Fact). Не показывать shadow-метрики глубины подсказок.
- **Пилюли-выбор** (radius 999, выбранная — терракота/wash) — mobile 17–19 паттерн, живёт в S3.
- **Кнопки**: primary терракота / ghost line, высота ≥48; нажатие scale .98 (slice-ui).
- **Строки настроек + тумблеры** (mobile 11, web 12).
- **Офлайн-набор**: «доступно офлайн», «снова в сети», «✓ загружены» (mobile 32).
- **Focus-тема «свет лампы»** (латунь #E8B36A на #211D16/#2E2A22) — режим, не идентичность.
- **Тон сообщества** (mobile 35: «можно просто слушать», отказ без объяснений) — копирайт-канон.
- **Честность оплаты** (mobile 28: «напоминание до списания · отмена в два тапа · без таймеров скидок») — Г-4-канон.
- **Токены** packages/tokens/index.ts — единый источник: палитра light/dark, флаги навыков, радиусы 12/16/22/999, Golos/Lora. Канон без изменений значений.

## 2. Компоненты — ADAPT
- **Фазовая полоса сессии**: 4 навык-цвета «поток→контекст→узнавание→своё» → 6 честных фаз (прайминг · встреча · извлечение · производство · голос · резюме); цвет — по классу фазы, не по «навыкам».
- **Карточка слова (прайминг/SRS)**: убрать самозаявления («Знаю», «Помню и могу сказать») → тап-послушать / нейтральные исходы; направление карточки (узнаю ↔ говорю) видимо.
- **Статус слова в словаре**: одна шкала «новое/учу/закреплено» → направленная пара recognize/produce; «закреплено» только по свидетельству соответствующего класса.
- **Полосы прогресса дорожек**: без CEFR-якорей и «% до уровня»; полоса = факт процесса, способность = текст «что могу» с классом свидетельства.
- **Таб-бар / сайдбар**: состав ждёт нав-решения (A инструменты vs C гибрид, split_v2); ярлык «Аня · B1» из сайдбара убрать.
- **Push-карточки**: + состояния permission-denied ≠ opt-out, stale, missed ≠ отказ.

## 3. Устаревшие — не переносить
- Стражи-блобы и их палитра **в продукте** (Г-3); судьба вне продукта — решение владельца.
- CEFR-шкала A1–C1 и результат-карточка «Ты в зоне B1» (levelcheck).
- Счётчики «N подряд» / стрик-язык.
- Гейдж «часы из ~200 до B2».
- Карточки Галины внутри приложения (auth, приветствие).
- Сетка-каталог «Навыки».
- Онбординг язык/цель/время/уровень/страж.

## 4. Недостающие семейства (создать в Living Content)
- **Оценочный режим** (требуется новый дизайн; Batch 1 — только reference состояний): submit-lock, accepted-тик, нейтральный not-recorded, «Не помню» первого класса, эмоциональный контракт, прогресс «N из 28».
- **Лесенка опоры извлечения** (S5 ф.3): буква → выбор из 3 → показ+перепечатать, ретрай; только учебный режим.
- **Жизненный цикл записи голоса**: permission-undetermined/denied · recording · interrupted · empty · storage/playback-failure → письменный поток без spoken-claim (S5/S10/S22 единообразно).
- **Библиотека состояний S27**: saved-local ≠ core-accepted · pending-sync · not-saved · storage-unavailable · sync-conflict; идемпотентный повтор.
- **AI Summary карточка** (S14): признание · «ещё так говорят» · грамматика к случаю · плашка честности источника; shown/unavailable/manual-retry/stored-copy.
- **Журнал целостности данных** (S1 M3): честное объяснение + явный выбор.
- **Waitlist/не-подходит** (M4): без стыда.
- **Мини-лекции инфографикой** [PLAN, S15b] — место зафиксировано, не проектировать.

## 6. Доступность — исправления по системе
1. Подписи #9a917f/#b0a893 на бумаге < AA для мелкого текста → минимум muted #6F6857; body обычно ≥16px, secondary обычно ≥14px; меньший текст допустим только для вспомогательных нетекстовых меток после проверки контраста и масштабирования.
2. Хит-таргеты: пилюли/иконки 30–34px → ≥44px (моб.).
3. Фокус-состояния клавиатуры: определить видимый focus-ring (2px терракота offset 2) для web.
4. prefers-reduced-motion: подтверждено (без дыхательных кругов); анимации прогресса — тихие, отключаемые.
5. Аудио всегда с транскриптом; голос — не единственный путь (текст-альтернатива).
6. Автокоррекция off только в оценочном/извлечении — помечать подписью, не молча.
