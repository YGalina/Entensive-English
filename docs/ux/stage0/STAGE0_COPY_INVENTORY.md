# Stage 0 · Копирайт-инвентарь (learner-строки)

Статусы: **FROZEN** — строка из замороженного пакета, менять нельзя · **LOCK** — черновик, но смысл семантически заперт (перефразировать можно, смысл — нет) · **DRAFT** — черновик, финальная формулировка за Fable (в границах firewall).
Firewall: во ВСЕХ строках запрещены «пилот/протокол/holdout/измерение/целевая единица/эксперимент», CEFR/уровни/проценты, стрики, внутренние ID (S5/T1/E3/N1/D4…). Инвентарь проверен — нарушений нет; Fable обязан сохранить это свойство.

| ID | Строка | Статус |

| C-D5-T / C-D5-G | Написать статус / «Коротко коллеге: что в процессе, что готово, что дальше» | DRAFT |

| C-ERR-AU2 | Этот шаг — про звук, без него не получится честно. Перенесём его на завтра. | LOCK (честный перенос) |

**Итого строк: 78** (FROZEN/канон 18 · LOCK 24 · DRAFT 36). Правило: Fable меняет слова DRAFT-строк свободно, LOCK — сохраняя смысл, FROZEN — не трогает.
