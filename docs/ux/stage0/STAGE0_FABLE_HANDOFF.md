## 2. Что Fable производит

1. **12 NEW-поверхностей (49 состояний)** — основной объём. Приоритет по зависимости дней: план дня (№1) → «Заметь закон» (№10) + управляемая вариация (№11) → decoding-клип (№12) → произношение-перцепция (№13) → ход разговора (№15, включая аудио-вариант №16) → беглость-версии (№17) → закрытие дня (№20) → новая ситуация (№21) → закрытие модуля (№22) → вопрос на смысл (№5, под-состояние ф2).
2. **2 ADAPT-поверхности (6 состояний)** — разбор модели письма (паттерн S21) и своё письмо-статус (паттерн ф4, длиннее): меняется только контент и длина, не паттерн.
3. **Финальные формулировки 36 DRAFT-строк** копирайт-инвентаря.
4. **Состояния прерывания/resume/ошибки для каждой NEW-поверхности** по разделу §3 контракта — они часть поставки, не «потом».

## 3. Что Fable НЕ трогает

- **8 REUSE-поверхностей (38 замороженных состояний)**: круг возврата (Batch D), ф1–ф5 ядра S5 (Batch C), резюме S14, шэдоуинг S22 (Batch E). Контент внутри них меняется по контракту; сами экраны, их состояния и визуальный язык — нет.
- **18 FROZEN-строк** копирайта. **24 LOCK-строки** можно переформулировать, но не менять смысл (в инвентаре у каждой указано, какой именно смысл заперт).
- **Основное приложение**: S1–S4, S6, S7–S13, S16–S20 не перепроектируются. План дня (№1) — контейнер ведомого потока Stage 0, он **не заменяет S4 Path Hub**.
- **Визуальный язык**: Living Content и утверждённая навигация Batch A/B/C — как есть.
- **Методология**: состав дней, минуты, контракты завершения, порядок блоков. День не сокращается ради того, чтобы поместиться в существующий S5.

## 5. Обязательства firewall (проверяется при приёмке)

Во всех learner-строках, включая новые формулировки Fable, **запрещены**: «пилот», «протокол», «holdout», «измерение», «целевая единица», «эксперимент», «исследование»; CEFR, уровни, проценты, «мастерство»; стрики и «N дней подряд»; внутренние ID (S5, T1, E3, N1, D4 и т. п.); психологические интерпретации; заявления, что какой-либо акцент «нейтральный».

Обязательны: честные минуты · один явный следующий шаг · тишина во время свободного производства (никаких подсказок) · ступенчатая опора только в структурированном извлечении · приватность голоса (записи не анализируются продуктом) · «не помню» — валидный ответ · без вины при коротком пути.

Инвентарь на момент передачи проверен, нарушений нет. Сохранить это свойство — обязательство Fable.

## 6. Критерии приёмки

1. Каждая NEW/ADAPT-поверхность покрыта состояниями из карты — включая resume, ошибку сохранения и недоступность аудио, где они указаны.
2. Ни один REUSE-экран не изменён; ни одна FROZEN-строка не переписана; смысл LOCK-строк сохранён.
3. Сумма минут по дням совпадает с контрактом (30/39/41/40/40/35/31), короткие пути соответствуют указанным составам.
4. Контракты завершения дней реализуемы ровно так, как записаны (что именно засчитывает день).
5. Research-поверхности нигде не появляются внутри блоков; единственная точка — нейтральная строка-ссылка после закрытия дня.
6. Прогон копирайт-firewall по всем строкам — чисто.
7. Нигде не появляется утверждение, что «S5 — это блок, а не день», как продуктовое решение: для продукта это Draft ADR, не утверждённое направление. Stage 0 — ручная доставка одного модуля.
