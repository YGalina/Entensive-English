## 0. Инварианты (нарушение любого = провал приёмки)

1. Составные дни **30–41 минута** (30/39/41/40/40/35/31); тайминги честные, без сжатия ради экрана.
2. Никакой групповой инструкции: ни классов, ни когорт, ни пар, ни клубов в контракте дня.
3. Ни одного заявления об уровне/CEFR/«освоении»; закрытия — только факты сделанного.
4. В learner-копирайте запрещены: «пилот», «протокол», «holdout», «измерение», «целевая единица», research-язык, внутренние номера экранов (S5, T1, E3, N1…) и ID файлов.
5. **Тишина во время свободного производства** (своя фраза, письмо, ходы сценария, версии беглости, перенос): ни подсказок, ни исправлений, ни счётчиков во время ввода.
6. **Лесенка опоры — только в структурированном извлечении** (блок «Вспомни и напиши»); больше нигде.
7. Голос приватен: опционален, не анализируется, «дальше без записи» — полноправная кнопка.
8. Честная нагрузка: план дня показывает реальные минуты; короткий путь честно помечается поддерживающим, без вины.
9. Один ясный следующий шаг на каждом экране; ровно один терракотовый CTA.
10. Living Content и утверждённая навигация: Stage 0 не меняет S4/Path и продуктовую навигацию; поверхности Stage 0 живут как отдельный ведомый контур (см. Handoff §Доставка).

## 1. Канонические блок-контракты (единый источник поведения)

Каждый день собирается ТОЛЬКО из блоков ниже. Блок = контракт: экран/компонент · вход · взаимодействие · завершение · фидбэк · ретрай · аудио · свидетельство · выход · состояния. Дни (§2) добавляют только контент и минуты. Копирайт-строки — по ID из `STAGE0_COPY_INVENTORY.md` (C-…).

### B1 · Круг возврата
- **Назначение:** продуктивное извлечение целей прошлых дней (смысл→форма).
- **Экран:** повтор-карточки **Batch D (frozen)** — REUSE; контент-адаптация: только карточки модуля.
- **Вход:** из плана дня; заголовок C-B1-T; счётчик «k из n».
- **Взаимодействие:** русский смысл → попытка вспомнить (про себя/вслух) → тап «показать» → самоисход: C-B1-O1 «вспомнила» / C-B1-O2 «вспомнила с трудом» / C-B1-O3 «не вспомнила». Ответ никогда не виден до попытки.
- **Завершение:** все n карточек пройдены (любыми исходами).
- **Фидбэк:** только показ формы; без оценок. «Не вспомнила» = C-B1-N (вернётся раньше, без штрафа).
- **Ретрай:** нет (исход = данные интервала).
- **Аудио:** озвучка формы по тапу (карточные записи не требуют диктора — TTS здесь допустим? НЕТ: решение A3 — карточки могут озвучиваться TTS; фиксируется в Handoff).
- **Свидетельство:** `retrieval-attempt{item, outcome}` — process.
- **Выход:** следующий блок плана.
- **Состояния:** очередь · карточка-вопрос · карточка-ответ · круг завершён · прерван→resume (продолжить с текущей карточки).

### B2 · Ядро S5 (шесть фаз, заморожено)
- **Экраны:** `batch-c-correction-v1` S5 ф1–ф5 + S14 — **REUSE без изменения механики**; контент-адаптация: списки до 5 единиц, тексты модуля.
- **ф1 Прайминг:** единицы дня с переводом и озвучкой; заданий нет (C-F1-*). Состояния: список · завершён.
- **ф2 Текст дня:** связный текст, цели подсвечены, тап-перевод, озвучка неблокирующая (C-F2-*). **+ НОВОЕ под-состояние «вопрос на смысл» (гейт):** 1 вопрос, 3 варианта (контент — E2 дня); неверно → C-G-H1 «посмотри на последние две реплики» → повтор; второй неверный → показать нужный фрагмент подсвеченным и идти дальше (гейт не блокирует день). Состояния: текст · озвучка играет · озвучка недоступна (C-ERR-AU) · вопрос · вопрос-повтор · фрагмент-показан.
- **ф3 Вспомни и напиши:** извлечения дня ×2–3; английского на экране нет; автокоррекция off (подписано C-F3-A); **лесенка**: буква→выбор из 3→показ+перепечатать; ретрай после любой ступени; без красного. Состояния: ввод · ступень 1/2/3 · верно · ретрай.
- **ф4 Своя фраза:** задача дня (C-D{n}-PROD); тишина во время ввода (C-F4-S); «Сохранено на устройстве» — локально, честно; после отправки: мягкий надж ТОЛЬКО при отсутствии форм дня (C-F4-N шаблон) + «оставить как есть» (C-F4-K). Состояния: ввод · сохранено-локально · надж · оставлено-как-есть · не-сохранилось (честно, ретрай).
- **ф5 Голос (опц.):** полный замороженный lifecycle записи (8 состояний, включая permission-denied и сбои → письменный поток без spoken-claim). C-F5-*.
- **ф6 Резюме (S14):** тёплое резюме по написанному, ПОСЛЕ; плашка источника; недоступно → C-S14-U + ручной повтор; вывод не блокируется. Состояния: показ · недоступно/retry · сохранённая копия.
- **Завершение блока:** ≥1 извлечение И 1 производство (замороженный контракт S5).
- **Свидетельства:** encounter · retrieval-attempt · production-submitted · voice-ref(опц.) — process.

### B3 · «Заметь закон» (микро-якорь)
- **НОВОЕ** (микро-карточка). Показ 90 сек: 2 пары из текста дня рядом + 1 строка смысла (C-B3-*). Взаимодействие: прочитать → «дальше». Без вопросов, без правил-лекций. Состояние: показ. Свидетельство: `anchor-shown`.

### B4 · Управляемая вариация (3 режима одного паттерна)
- **НОВОЕ** (собирается из утверждённых компонентов: поле ввода S5-ф3-класса, чипы, аудио-плеер).
- **Режим A · Подстановка:** рамка фиксирована, 3 своих слота (C-B4A-*). Приём: рамка сохранена. Рамка съехала → prompt C-B4-P1 + ретрай.
- **Режим B · Трансформация «скажи так»:** свой факт по-русски → своя фраза через форму дня; 3 задания (C-B4B-*). Приём: выбор формы соответствует смыслу. Prompts C-B4-P2/P3 (все past → «а что продолжается?»; все продолженное → «а что закончено и когда?»).
- **Режим C · Listen-then-build:** услышала фразу (без текста) ×2 → одна строка «о чём это» по-русски → своя фраза по модели (C-B4C-*).
- **Фидбэк во всех режимах:** ПОСЛЕ отправки; одно признание + одна альтернатива, поданная как ДРУГОЙ способ сказать (никогда как «та же цель»). Ретрай: вторая версия сразу, по желанию. Пропуск задания — полноправная кнопка (C-B4-SKIP).
- **Состояния:** инструкция · ввод (тишина) · принято+альтернатива · prompt+ретрай · пропущено.
- **Свидетельства:** `guided-attempt{mode, accepted}` — process.

### B5 · Слышу быструю речь (decoding)
- **НОВОЕ.** Клип 2–4 сек (без транскрипта; материал только уже разобранный) → C-B5-Q «Что ты услышала?» → 3 варианта (различие = слабая форма/связка) → после выбора: написание + медленно + снова быстро + одна строка объяснения (C-B5-E шаблон). Переслушивание не ограничено. Неверно — не ошибка-красный: показ и переход.
- **Состояния:** проигрывание · выбор · раскрытие (верно) · раскрытие (после неверного) · клип-набор завершён · аудио-недоступно (C-ERR-AU → блок откладывается на завтра, день не ломается).
- **Свидетельства:** `decoding-attempt{clip, correct, replays-shadow}`.

### B6 · Произношение: сначала услышать
- **НОВОЕ (перцепция) + REUSE S22-механика (артикуляция/шэдоуинг)**.
- **Шаг 1 перцепция:** пары «где ударение?» на слух (3 пары: figure OUT · sort OUT · put OFF — ТОЛЬКО эти три, правило `7982972`) + «где существительное?» для estimate. До любого говорения.
- **Шаг 2 артикуляция:** повтор 3 фраз за образцом; запись приватна (S22 замороженные состояния записи).
- **Шаг 3 в своей речи:** одна своя фраза с любым из трёх фразовых.
- **Ориентир, не оценка:** C-B6-O; баллов и оценки акцента нет; записи не анализируются.
- **Состояния:** пара-выбор · раскрытие · набор завершён · запись-lifecycle (S22 frozen: разрешение/запись/записано/прослушать/сбой-сохранения).
- **Свидетельства:** `stress-perception{correct}` · shadowing-ref (не анализ).

### B7 · Шэдоуинг
- **REUSE S22 (frozen)**; контент-адаптация: 3 фразы дня. Гейт понимания уже пройден (текст разобран в предыдущие дни) — C-B7-G «Смысл уже разобран» (канон Batch E). Ориентир «ритм совпадает», без баллов.

### B8 · Ходы разговора (сценарий)
- **НОВОЕ.** Сцена: реплика собеседника (аудио + текст; в дне 6 — только аудио) → (опц. до ввода) подсказка-стратегия C-B8-S → **свой ход** письмом или голосом (тишина во время ввода) → следующая сцена. Сцена 2 включает repair: реприза «Sorry — say that again?» → переформулировать ту же мысль другими словами (C-B8-R).
- **Фидбэк:** после ВСЕХ сцен: одно признание + одна альтернатива на выбранный ход + (если формы дня не всплыли) мягкое «вот эти две фразы сюда бы легли» (C-B8-F).
- **Состояния:** реплика · стратегия (опц.) · ввод хода · ход принят · реприза · фидбэк-после-всех · аудио-недоступно (текст-фолбэк, кроме дня 6 — там блок откладывается).
- **Свидетельства:** `scenario-turn{scene, modality}` · `repair-turn`.

### B9 · Беглость (версии)
- **НОВОЕ** + REUSE голос-lifecycle S5-ф5 для записи.
- **Мини (Д1):** свою фразу вслух дважды; вторая — без текста.
- **Пере-рассказ (Д4):** версии 2 и 3 рассказа «что я успела», каждая «чуть короче» (C-B9-I: «не гонись — просто меньше пауз»); БЕЗ таймера-обратного-отсчёта и красного; длительность — shadow.
- **Полная (Д6):** три версии: с опорами (текст) → чипы → без ничего; между версиями пауза 30 с; «вернуться к опорам» доступно всегда и не помечается неудачей (C-B9-B).
- **Гейт:** только материал, чья рамка сформирована в предыдущие дни; материал сегодняшнего первого знакомства в сжатие не идёт.
- **Состояния:** версия-подготовка · говорение (тишина) · пауза-между · опоры-возвращены · завершено.
- **Свидетельства:** `fluency-version{n, support-level, duration-shadow}`.

### B10 · Письмо: статус
- **ADAPT:** разбор модели — паттерн читалки S21 (frozen) с подсветкой трёх ходов; своё письмо — производственное поле класса S5-ф4, длиннее (4–6 предложений), каркас трёх ходов на экране (C-B10-K), тишина во время письма; резюме S14-класса ПОСЛЕ.
- **Состояния:** модель · ходы-подсвечены · каркас+ввод · сохранено-локально · резюме · не-сохранилось (честно).
- **Свидетельства:** `writing-submitted{sentences}` · артефакт письма (в «Мои артефакты»-класс хранения).

### B11 · Новая ситуация (день 7)
- **НОВОЕ** (вариант B8 без подсказок). Вводная C-B11-I (без анонса содержания заранее); 4 реплики подруги (аудио+пауза) → свой ответ голосом ИЛИ письмом; никаких чипов и подсказок; RU-опора текста — только ПОСЛЕ выполнения; после всех четырёх: тёплое резюме + ретрай по желанию (учебная задача; для данных считается первая версия — но learner этого не видит и не должен видеть).
- **Состояния:** вводная · реплика→ответ ×4 (тишина) · выполнено · RU-опора раскрыта · резюме · ретрай.
- **Свидетельства:** `transfer-response{turn, modality}` (research-контур помечает first-version отдельно; в learner-опыте различия нет).

### B12 · Закрытие дня «Что стало ближе»
- **НОВОЕ (микро).** 2–4 факта дня строками «что делала» (шаблоны C-B12-*); без процентов, уровней и похвал-оценок; строка завтрашнего шага одной фразой без деталей (для Д6 — C-B12-D6 «завтра — то же самое, но в другой ситуации»). Состояние: показ.

### B13 · Закрытие модуля (день 7)
- **НОВОЕ.** Факты недели (C-B13-F: дни · сказала вслух N раз · письмо N предложений · быстрая речь N фрагментов) + C-B13-R «часть слов вернётся — мы принесём их снова» (канон Batch D «вернём их под руку») + приглашение вернуться через неделю C-B13-P («посмотрим, что осталось само» — БЕЗ слов «проверка/тест/экзамен» как угрозы; формулировка мягкая, зафиксирована). Состояния: факты · приглашение.

### B14 · План дня (контейнер)
- **НОВОЕ (единственный настоящий контейнер Stage 0).** Показывает: заголовок дня (C-D{n}-T) + цель дня одной строкой (C-D{n}-G) + честные минуты + последовательность блоков как ОДИН ведомый поток (не меню!): всегда виден только текущий шаг и «дальше».
- **Короткий путь:** доступен с плана дня и с любого блока кнопкой C-SP-B «Сегодня короче»; показывает состав короткого пути дня (C-SP-D{n}) и честную подпись C-SP-H («День не прерван. Остальное подхватим завтра» — без вины); завершение короткого пути = день закрыт поддерживающе, помечается в данных `short-path`, learner видит нейтральное закрытие.
- **Прерывание/resume:** выход в любой момент валиден; при возврате — C-RS-T «Ты остановилась на …» + продолжить с ТЕКУЩЕГО блока (внутриблочные черновики — по правилам блока; ф4/письмо возобновляют черновик).
- **Состояния:** план · блок m из n · resume · день завершён · день завершён коротким путём · день не начат к вечеру (нейтрально, без пушей в Stage 0).

## 2. Дни: инстанциация

Формат строки: № · блок · learner-заголовок (C-ID) · контент · минуты · обяз/опц.

### День 1 · «Что у меня в процессе» (30 мин) — C-D1-T/G
1. B2 Ядро: ф1 «Четыре фразы на сегодня» (N1–N4) → ф2 «Текст дня» T1+A1, вопрос E2-Д1 → ф3 извлечения E3-Д1 ×3 → ф4 «Своя фраза» (C-D1-PROD «Над чем ты работаешь прямо сейчас — на работе или дома? 2–3 фразы») + чипы 4 форм дня → ф5 голос опц. → ф6 резюме · 16′ · обяз.
2. B4-A Подстановка «Продолжи про себя» — `I've been working on ______` ×3 · 8′ · обяз.
3. B9-мини «Скажи вслух дважды» · 4′ · желат.
4. B12 Закрытие · 2′ · обяз.
- **Контракт дня:** блоки 1–2 (внутри 1 — S5-контракт). **Короткий путь (≈14′):** ф1→ф2→1 извлечение→ф4; подстановка уходит в Д2. **Завтра:** формы дня → круг возврата; фраза дня — материал беглости Д2.

### День 2 · «Что сделала и что делаю» (39 мин) — C-D2-T/G
1. B1 Круг: 4 карточки (формы Д1) · 3′ · обяз.
2. B2 Ядро: ф1 (N5–N8) → ф2 T2+A2, вопрос E2-Д2 → ф3 ×3 → ф4 (C-D2-PROD «Напиши коллеге: что в процессе и что уже закончила») → ф6 · 16′ · обяз.
3. B3 «Заметь закон»: пары *I've been working ↔ I finished yesterday* · 3′ · обяз.
4. B4-B Трансформации ×3 (идёт → закончено → обе подряд) · 10′ · обяз.
5. B4-C Listen-then-build ×2 · 5′ · желат.
6. B12 Закрытие · 2′ · обяз.
- **Контракт:** 2 и 4 (в 4 — ≥2 из 3). **Короткий (≈16′):** круг → ядро сокращённо; 3–5 уходят в Д3. **Завтра:** те же тексты в быстрой озвучке.

### День 3 · «Услышать это быстро» (41 мин) — C-D3-T/G
1. B1 Круг: 8 карточек · 5′ · обяз.
2. Быстрый вход: A1-f ×2, текст по кнопке ПОСЛЕ первого прослушивания (C-D3-L) · 6′ · обяз.
3. B5 Decoding: D1→D4→D2→D3 · 10′ · обяз.
4. B6 Произношение: перцепция (3 пары + estimate) → артикуляция 3 фразы → своя фраза · 9′ · обяз.
5. B7 Шэдоуинг: 3 фразы из T1 · 6′ · желат.
6. Голос: фраза Д1 вслух в естественном темпе (запись опц.) · 3′ · желат.

## 3. Сквозные правила состояний

- **Прерывание любого блока** → resume с текущего шага; черновики производств сохраняются локально и возобновляются; ничего не пересоздаётся.
- **Аудио недоступно:** блоки, где аудио — суть (B5, B8-Д6, быстрый вход) — честное «сегодня без звука не получится» C-ERR-AU2 + блок переносится, день закрывается остальным; блоки, где аудио — поддержка (ф1/ф2/карточки) — продолжаются без звука.
- **Не сохранилось:** всегда честно, всё введённое остаётся на экране, повтор явный (канон S3/S27).
- **Пустых состояний-приглашений** в Stage 0 нет (контент фиксирован); «пусто» возможно только в круге Д1 — его нет by design.
- **Никаких пушей/напоминаний** внутри Stage 0 (research-контур, доставка ручная).
- Research-поверхности (скрининг, pre/post/+7, ежедневные вопросы, интервью, согласие) — ВНЕ learner-потока дней; см. карту, класс RESEARCH; в дни не встраиваются, кроме нейтральной строки-ссылки после закрытия дня (C-RQ-L «Короткая анкета дня — 1 минута», вне контракта дня).
