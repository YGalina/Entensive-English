## Что блокирует старт пилота

1. **Записи диктора** (8 файлов + нарезки) — без них дни 3 и 5 не идут.
2. **Методологическое ревью** набора проб pre/post/+7 и порогов калибровки оценщиков.
3. **Решение по общим карточкам** для кругов возврата (§5 открытых решений).
4. Юридическая вычитка текста согласия.
Всё остальное готово к передаче Fable на редактуру формулировок — **после** методологического ревью, не раньше.
