# День 3 · «Услышать это в быстрой речи»

**Цель дня:** ты узнаёшь знакомые фразы, когда их произносят быстро, и ставишь ударение во фразовых глаголах туда, куда носитель.
**Пререквизит:** дни 1–2. **Гейт:** decoding идёт только по текстам, смысл которых уже разобран (иначе это имитация без понимания).
**Новое:** ноль новых лексических целей. Это день модальности, а не объёма.
**Возврат:** N1–N8 (все восемь целей — в SRS и в звучании).

## Контракт завершения

Блоки 3 и 4 выполнены (4 decoding-задания + перцепция ударения). Блок 5–6 — желательные.
**Особый случай:** этот день не содержит письменного производства. Инвариант «≥1 извлечение + ≥1 производство» выполняется через блок 1 (извлечения) и блок 6 (устное производство). Если голос недоступен — засчитывается проговаривание вслух без записи (никаких spoken-claim в данных).
