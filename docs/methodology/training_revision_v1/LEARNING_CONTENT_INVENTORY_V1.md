## 2. Что требуется одному 7-дневному модулю (норматив производства)

| Тип контента | Штук/модуль | Есть для модуля 1? | Комментарий |
|---|---|---|---|
| Связные тексты-диалоги/монологи (80–140 слов) | 3–4 | 2 из 4 (банк среза + Batch C) | тексты №2 «что я успела» и №3 «передвинуть срок» — написать |
| Озвучка текстов: нормальный + беглый темп | 2 версии × тексты | нет | один диктор; беглая версия обязательна для СД-блока [R decoding] |
| Decoding-фрагменты (5–10 сек, редукции) | 6–8 | нет | нарезаются из беглых озвучек |
| Произносительная черта: пары/стресс-набор | 1 черта, 6–8 позиций | нет | по инвентарю модуля |
| Целевые единицы с примерами/переводами | 12 новых + 6 реактивных | ~70% | добить 4–5 карточек |
| Guided-задания («скажи через X», подстановки, listen-then-build) | 10–14 | частично (6 трансформаций среза) | дописать 6–8 |
| Сценарные диалоги ИР (3 хода × 3 сцены + аудио реплик) | 3 сцены | нет | реплики собеседника — фиксированные, не runtime-AI |
| Модель письма (text pattern) + каркас | 1 | нет | статус коллеге |
| Перенос-задача (novel, 4 реплики + аудио) | 1 | частично (банк нового контекста среза — но он в протоколе) | для ОБУЧЕНИЯ нужна отдельная, не протокольная |
| Копирайт всех экранных подводок | ~30 строк | нет | Fable + firewall |

**Оценка трудозатрат на модуль [H]:** методист 12–16 ч + диктор 1–2 ч + Fable-копирайт 3–4 ч + сборка/QA 4–6 ч ≈ **20–28 ч/модуль**. Для эксперимента нужно 3 сопоставленных модуля ≈ 60–85 ч + выравнивание.

## 3. Корпус «English with Daniel» как контент-источник

**Вердикт: не переносится как есть.** Причины: формат (декларативные гап-филлы с впечатанными ответами) противоречит ретрив-принципу [R]; фокус (narrative tenses, conditionals-3, prefixes) не совпадает с узким местом ЦА и последовательностью blueprint S1–S2; learner-facing язык не проходит firewall; **лицензия не установлена [U]** — до выяснения прав никакие тексты/предложения не копируются.
**Что корпус даёт легально:** карту тем, которые реальный преподаватель считает нужными этой аудитории [P]; свидетельство переносимой дневной нормы (1–3 содержательные единицы контента/день); идею persistent narrative между листами (сквозные герои — у нас уже реализовано героиней текстов среза).

## 4. Правила контент-производства (инварианты)

Единицы выбираются по таксономии v2 (kind определяет ввод/практику/SRS-судьбу); каждая единица живёт минимум в одном связном тексте ДО извлечения; ответы никогда не видимы до попытки [R testing effect]; метки сложности — только на материале, не на человеке; весь learner-facing текст — через copy-firewall; протокольные банки (22 trained до finalization, 6 holdout всегда) в учебный контент не подмешиваются; аудио — реальные дикторы или утверждённый TTS-канал [U решение владельца по качеству озвучки].

## 5. Очередь производства [H]

1. Достройка модуля 1 «Рабочий разговор» (частично готов) — для эксперимента, условие-агностично.
2. Модуль 2 «Переезд и быт» — второй домен эксперимента (частично опирается на new-context банк тем, но НЕ на его протокольные items).
3. Модуль 3 «Услуги и договорённости» — третий домен.
4. После эксперимента: конвейер модулей по blueprint-дорожкам (только при положительном решении о дозе).
