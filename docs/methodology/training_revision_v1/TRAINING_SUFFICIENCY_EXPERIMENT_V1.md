## Этап 0 · Разведочный пилот «состоит ли день из блоков» (запускается первым)

**Вопрос:** даёт ли составной устойчивый день (Режим 2, собранный вручную) правдоподобный сигнал лучшего удержания/переноса и приемлемой нагрузки по сравнению с текущим лёгким S5-днём — достаточный, чтобы оправдать Этап 1 и контент-конвейер?

**Статус по определению: разведочный.** Не имеет статистической мощности; не доказывает причинность; его результат — «сигнал есть / сигнала нет / вред», не эффект-сайз.

### Дизайн

- **Участницы:** **5–8** взрослых ЦА (профиль пяти признаков S3, скрининг-колл как Г-1).
- **Контент:** **один вручную произведённый модуль** — `SEVEN_DAY_INTENSIVE_MODULE_V1` («Рабочий разговор», прототип Этапа 0). Никакого конвейера из трёх модулей.
- **Оркестровка — ручная, без кода:** дни составного условия ведутся «дирижёрским» протоколом (ежедневный план-последовательность; существующие продуктовые поверхности где есть + внешние материалы: аудиофайлы, документы, формы). **Runtime-композитор Daily Engine НЕ требуется и не пишется.** Экспериментальный контур изолирован от продуктовых данных.
- **Сравнение:** каждая участница проходит ДВЕ недели:
  - неделя-A: **текущий S5-опыт как есть** (лёгкий цикл на существующем lean-контенте продукта);
  - неделя-B: **составной устойчивый день** (модуль, Режим 2, 35–50 мин).
  Порядок контрбалансирован (половина A→B, половина B→A).
- **Честное ограничение дизайна (заявляем, не прячем):** контент недель РАЗНЫЙ (lean-контент ≠ модуль), объём экспозиции разный, а перенос навыка между неделями внутри человека существует и **не устраняется паузой** — межнедельная пауза 2–3 дня служит отдыху и логистике, **не** «очистке» эффекта. Поэтому сравнение интерпретируется как «два продуктовых опыта у одних людей», а не как изолированный причинный эффект дозы.

### Меры Этапа 0

| Момент | Мера |
|---|---|
| Pre (до каждой недели) | продуктивный ретрив проб целевых единиц предстоящей недели (смысл→форма) — фиксирует стартовое незнание |
| Immediate (последний день недели) | продуктивный ретрив целевых единиц недели |
| **Delayed +7** после каждой недели | тот же ретрив (другой порядок) |
| Перенос (только неделя-B, день 7) | novel-задача модуля (4 реплики) |
| Нагрузка (после каждой недели) | краткая шкала нагрузки (усилие/темп/фрустрация, Likert-7 [H формулировки]) + фактическое время по дням |
| Достаточность (после каждой недели) | «дня хватало, чтобы чувствовать движение» и ещё 2 пункта Likert-7 [H] |
| Поведение | завершения дней, обрезки, пропуски, точка бросания |
| Качественное | полуструктурированное интервью 30 мин после обеих недель (6 вопросов по образцу validation_v2 + «сравни недели») |
| Голос (опц., по отдельному согласию) | 60-сек рассказ о работе в конце недели-B — только человеческое прослушивание |

**Деноминаторы (обязательное правило):** удержание считается **среди фактически встреченных единиц** (encountered), отдельно фиксируется **сколько всего единиц недели встречено** (экспозиция) и **фактическое время**. Неделя-A закономерно встречает меньше — это часть сравниваемых опытов, а не «шум».

### Сигнальные критерии Этапа 0 (все [H], разведочные, не пороги доказательства)

Позитивный сигнал = выполняется большинство из:
1. удержание-among-encountered недели-B на delayed+7 не хуже недели-A, при том что B охватывает заметно больший инвентарь;
2. в переносе дня 7 ≥ половины участниц употребляют ≥1 целевую единицу;
3. воспринимаемая достаточность B > A у большинства;
4. нагрузка B оценивается как посильная (медиана ≤5/7) и нет отвала, связанного с объёмом (по интервью);
5. интервью не выявляют системного отторжения составного дня.
Негативный сигнал (любой): отвал ≥ половины на неделе-B по причине объёма · удержание B заметно хуже A · интервью единодушно «слишком много». Тогда пересмотр состава Режима 2 ДО любых затрат на конвейер.

### Стоимость и сроки [H]
Один модуль (достройка ~20–28 ч по инвентарю) + рекрутинг 5–8 + 3 недели полевых + интервью. Без кода, без дизайна, без конвейера.

## Этап 1 · Трёхусловное сравнение доз (запускается ТОЛЬКО при позитивном сигнале Этапа 0)

Сохраняется прежний дизайн с исправлениями. Условия: **A** лёгкий S5-день · **B** устойчивый составной (Режим 2) · **C** интенсивный (Режим 3).

- **Дизайн:** within-participant, латинский квадрат 3×3 (порядковые группы), **N=12–18**, три сопоставленных модуля (работа/переезд/услуги; сопоставление по числу и типам единиц, классу конструкции, длине и покрытию текстов).
- **Эффекты порядка, периода и переноса — явно:** латинский квадрат **балансирует порядок между группами**, но НЕ устраняет (а) внутриличностный перенос навыка (участница делается сильнее от модуля к модулю — период-эффект; учитывается включением периода как фактора в анализ и сравнением внутри периода), (б) перенос стратегий между условиями, (в) взаимодействие условие×модуль (смягчено ротацией модуль↔условие). **Межмодульная пауза 2–3 дня — логистическая; заявлений о «снятии переноса» не делается.** Малое N делает поправки грубыми — выводы формулируются как «направление при заявленных ограничениях».
- **Пригодность по времени (исправлено):** требования к доступности — **по самому тяжёлому назначенному условию**: недели-C требуют 60–90 мин/день, недели-B 35–50, недели-A 15–20. Так как each-does-all, набор идёт под C: **≥90 мин/день доступности** на C-неделе. **Селекционное смещение фиксируется как ограничение:** выборка, способная на 90 мин/день, нерепрезентативна для будущих пользователей Режимов 1–2; выводы о достаточности Режима 2 из Этапа 1 распространяются на генеральную аудиторию с осторожностью. Опция-снижение смещения [H]: стратифицировать набор («могу 90» vs «могу 50, C пройду в минимально-допустимой обрезке 60»), если владелец принимает удлинение набора.
- **Деноминаторы и экспозиция (исправлено):** для каждого условия репортятся РАЗДЕЛЬНО: (1) удержание among-encountered (immediate, +7, +14); (2) **всего приобретено из полного инвентаря модуля** (деноминатор = 12±1 единиц — «сколько инвентаря конвертировано», прямо зависит от экспозиции); (3) перенос (novel-задача, счёт всплывших единиц); (4) фактическая экспозиция (встречено единиц, минуты, завершения). **Интерпретация:** сравнение условий — это сравнение «пакетов дозы» (экспозиция+возможности практики+время различаются вместе); чистый причинный эффект «дозы» не заявляется.
- **Меры, слепая оценка, роль LLM, согласие** — как в v1: delayed +7/+14; speaking/writing-образцы по отдельному информированному согласию в изолированном research-контуре (FD-6-связка); 2 слепых человеческих оценщика (comprehensibility 1–9 [R: класс шкал Derwing & Munro — см. Приложение], счёт целевых единиц, CAF-лайт, связность 1–5); калибровка (κ≥0.6 [H рабочий порог]); **LLM не выносит суждений об эффективности** — только сверка качества AI-резюме с человеческой разметкой.
- **Пороги решений** (проценты удержания, +1.0 Likert, ±15/20 п.п. отвала, +15% слогов/мин) — **все [H]: рабочие пороги продукта, назначенные до анализа; не литературные константы.** Утверждаются с независимым методологом до старта Этапа 1 (решение №10 → перед Этапом 1, не Этапом 0).
- **Аналитика:** exp-события v1 без изменений; изоляция от продуктовых данных.

## Ворота между этапами

Этап 1 стартует только если: Этап 0 дал позитивный сигнал И владелец утвердил бюджет конвейера (3 сопоставленных модуля ≈60–85 ч) И пороги Этапа 1 согласованы с методологом. Негативный/смешанный сигнал → итерация состава дня и повтор Этапа 0 (дёшево), НЕ Этап 1.

## Ограничения программы (сводно, честно)

Этап 0: разведочный, разный контент условий, carry-over не устраним, N мал. Этап 1: пакетное (не изолированное) сравнение доз; период/перенос-эффекты при малом N; самоотбор по доступному времени; 14 дней не показывают долгую кривую. Все публикуются с результатами.
