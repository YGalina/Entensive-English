## A. Требуются ДО Этапа 0

| № | Решение | Контекст | Опции | Рекомендация |
|---|---|---|---|---|
| A1 | **Утвердить Этап 0 как таковой** (объём и бюджет) | 5–8 участниц, **индивидуально и самостоятельно, без сравнительных условий и групповых форматов**; один достроенный модуль (~20–28 ч контент-работ [H]); ~1 неделя полевых + delayed-хвост (+7) ≈ 3 недели календарно; ручная оркестровка; без кода и дизайна | запустить / изменить объём / не запускать | запустить |
| A2 | **Согласие на речевые образцы** (FD-6-связка) | Этап 0 пишет опциональные голосовые образцы; продуктовый инвариант «голос не анализируется» обходится ТОЛЬКО явным research-согласием вне продукта | (а) согласие в рекрутинг-процессе (звонок + документ), продукт не трогаем; (б) строить consent-поверхность | **(а)** |
| A3 | **Канал озвучки модуля** | СД-блоку нужна беглая натуральная речь; TTS-редукции ненадёжны [H] | (а) диктор для decoding/текстов, TTS допустим для карточек; (б) всё диктор; (в) всё TTS | **(а)** |
| A4 | **Ратифицировать создание Draft ADR** «Композитный день» | Draft документирует направление; НЕ утверждается, реализацию не запускает | создать Draft / не создавать | создать Draft |
