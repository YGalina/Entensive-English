# Три режима дневной нагрузки · v1

Статус: на ревью владельца и независимого методолога · Дата: 2026-07-29 (коррекция v1.1)
База пакета: `377fdfa` (методологические источники не менялись — см. аудит).
Метки: [R] research (только со ссылкой — Приложение §8 аудита) · [P] precedent · [H] hypothesis · [F] founder · [U] unresolved. **Все числовые значения этого документа (минуты, лимиты единиц, объёмы ретрива, пропорции) — [H]: рабочие нормы продукта, мотивированные литературой, но не выведенные из неё количественно.** Проверяются двухэтапной программой валидации.

## Согласование с существующей доктриной

Репозиторий УЖЕ содержит режимы (`daily_learning_engine.md`: Минимум 5–8 · Стандарт 20–30 · Deep-work 45–90 · Live; `intensive_model.md`: Sustainable 30–40 мин/день · Accelerated 1–1.5 ч). Эта ревизия **не изобретает новую систему** — она калибрует три режима под требование владельца и собирает их из утверждённых блоков `training_block_architecture.md`.

| Режим v1 (этот документ) | Существующий прецедент | Дельта |
|---|---|---|
| Минимум непрерывности 15–20 мин | «Минимум 5–8» + начало «Стандарта» | **поднят пол** [F]; конфликт с утверждёнными 5–8 → решение владельца (`OPEN_METHODOLOGY_DECISIONS` №1) |
| Устойчивое ядро 35–50 мин | «Стандарт 20–30» + Sustainable 30–40 | расширен блоком беглости и слуха [F; состав блоков — P doctrine] |
| Интенсивный день 60–90 мин | Deep-work 45–90 / Accelerated | уточнён состав, добавлены защиты |

Сквозные принципы (без изменений, из доктрины): ученица выбирает **режим**, система раскладывает баланс [A→R]; каждый режим имеет финал «день собран», не чек-лист предметов; «пауза — не потеря»; сон: тяжёлое новое — не на вечер [H, мотивировано консолидацией памяти во сне; продуктовая рекомендация, не количественный результат]; никакой режим не гейтит оценку и не создаёт свидетельств сверх реально сделанного.

Обозначения блоков — из `training_block_architecture.md`: ЛР = лексический ретрив · ФР = фразеология · ГП = грам-процедурализация · СД = слух-decoding · ПР = произношение/просодия · БГ = беглость · ИР = interaction/repair · ПС = письмо · ЧТ/КН = чтение/книга · SRS = флеш-круг возврата. Замороженный S5 = реализация связки «ЛР/ФР-ядро + freer output» (фазы 1–6).

## Режим 1 · Минимум непрерывности — 15–20 мин

**Учебная цель:** удержать цепочку дней и не дать просесть выученному; лёгкий продуктивный контакт с языком. Это режим продолжения, «день не прерван» — **не** полный интенсивный опыт, и он не маркетируется как таковой [F, совпадает с доктриной «не „полноценная учёба“»].

| Параметр | Значение |
|---|---|
| Обязательные блоки | SRS-круг (5–7 мин, 8–12 карточек produce) → S5-микро (прайминг+встреча+1–2 извлечения+1 своя фраза; 8–10 мин) |
| Опциональные | голос (фаза 5); 1 shadowing-фраза |
| Новый материал | **0–3 единицы** [H] (можно день вовсе без нового — мотивировано приоритетом извлечения над вводом, см. Приложение §8: testing effect/spacing) |
| Объём возврата | 8–12 извлечений SRS [H] — возврат здесь главный, не довесок |
| Вход:выход | ~50:50 |
| Речь вслух | 0–2 мин, опционально (голосовая фаза) |
| Слух/произношение | пассивно (озвучка текста); отдельного блока нет |
| Чтение/письмо | нет (кроме 1 своей фразы) |
| Защита нагрузки | одна цепочка экранов, ноль выбора; никаких «а ещё можно…» |
| Критерий завершения | SRS-круг закрыт И 1 производство создано (совместимо с контрактом S5: ≥1 извлечение + 1 производство) |
| Перенос на завтра | невзятое новое остаётся в плане блока; недобранный ретрив — в очереди FSRS; система помечает «завтра продолжим блок» |

**Честная подпись режима** (копирайт-принцип, не финальный текст): день сохраняет непрерывность и возврат; рост объёма — в другие дни. Без вины, без «ты сделала мало».

## Режим 2 · Устойчивое ядро — 35–50 мин (дефолт продукта [H])

**Учебная цель:** полный дневной цикл acquisition: новый материал в контексте → извлечение → управляемая вариация → своя речь + возврат вчерашнего + одна нить слуха/произношения. Соответствует «Стандартному дню» доктрины, дополненному беглостью.

| Параметр | Значение |
|---|---|
| Обязательные блоки (порядок) | 1) SRS-круг 5–7 мин → 2) **S5-блок полный** (фазы 1–6; 12–15 мин; см. лимиты ниже) → 3) СД или ПР микро-блок 5–8 мин (чередуются по дням) → 4) Guided-вариация: «скажи через X» / подстановка на конструкции дня 5–7 мин (реализация ГП-блока) → 5) БГ-мини: пере-рассказ вчерашней/сегодняшней темы 2 версии (task repetition) 4–6 мин |
| Опциональные | ЧТ 5–10 мин (латерально, S21); дополнительный голос |
| Новый материал | **5–8 единиц** по таксономии: ~3–4 слова/коллокации + 2–3 chunks/фразовых + 1 конструкция (активная неделю, не новая ежедневно) [H: рабочий диапазон; прямой количественной нормы «новых единиц/день» для взрослых L2 литература не даёт — мотивировка через spacing/retrieval (Приложение §8 аудита); проверяется Этапами 0/1] |
| Объём возврата | 10–16 извлечений SRS [H] + повтор вчерашних целей внутри guided/беглости |
| Вход:выход | 55:45 → 50:50 [H, `intensive_model`; биологически-оптимальная пропорция не установлена [U]] |
| Речь вслух | 5–8 мин суммарно (голос S5 + беглость вслух; приватно, не анализируется) |
| Слух/произношение | ежедневно ~5–8 мин: чётные дни decoding (редукции/связки на аудио дня), нечётные — 1 произносительная черта (перцепция→артикуляция) |
| Чтение/письмо | письмо = производство S5 (2–3 фразы против нынешней 1); полноценный ПС-блок — в интенсивном дне; чтение — опционально |
| Защита нагрузки | один новый «тяжёлый» фокус в день (либо новая конструкция, либо новая произносительная черта — не обе) [H, мотивировано теорией когнитивной нагрузки — рамка, не количественный результат]; блоки 3–5 работают ТОЛЬКО на материале, уже прошедшем встречу |
| Критерий завершения | S5-контракт + SRS-круг + (СД/ПР) + guided-вариация выполнены; беглость опциональна для «дня собран», обязательна для недельного баланса |
| Перенос на завтра | цели дня → SRS produce day+1 [R: spacing, Приложение §8; сам шаг day+1 — конвенция FSRS]; конструкция недели остаётся активной; невыполненный СД/ПР-блок первым встаёт в завтрашний день |

## Режим 3 · Интенсивный день — 60–90 мин

**Учебная цель:** ядро + глубокая работа: письмо/грамматика-конструктор/длинный вход + расширенная беглость и interaction. Реализация Deep-work; mobile-утро + web-день (`17_platform_architecture`).

| Параметр | Значение |
|---|---|
| Обязательные блоки | весь Режим 2 (35–50) → далее web: 6) ОДИН deep-блок 15–25 мин: ПС «ответь на письмо» (3–6 предложений с опорами) ИЛИ ГП-конструктор ИЛИ КН/сцена (глава/фрагмент с pre/while/post-задачами) — ротация по дням недели → 7) БГ полный: 4/3/2 на СФОРМИРОВАННОМ фрейме (только после T4-повторов; гейт — Приложение §8: сама техника [R Nation 1989], «консервация ошибок на несформированном фрейме» — теоретическое расширение [H]) ИЛИ ИР: диалог с задачей и repair (AI по правилам S15 — когда активирован; до того — сценарные опоры) |
| Опциональные | второй deep-блок (не рекомендован ежедневно); подготовка миссии (если близко реальное событие) |
| Новый материал | **8–12 единиц** [H], но не более +4 к устойчивому дню; рост дозы идёт в ретрив/вывод, НЕ в ввод [H, согласовано с intensive_model [P]: интенсивность = плотнее цикл, не больше нового] |
| Объём возврата | 16–24 извлечения [H] + повторное употребление недельных целей в deep-блоке |
| Вход:выход | 50:50 |
| Речь вслух | 10–15 мин (беглость + interaction + голос) |
| Слух/произношение | оба микро-блока (decoding И произношение) |
| Чтение/письмо | deep-блок дня; письмо ≥2×/нед в этом режиме |
| Защита нагрузки | максимум 90 мин/день суммарно; после интенсивного дня следующий рекомендуется устойчивым или минимальным [H, мотивировано spacing/консолидацией — Приложение §8]; при 6–7 интенсивных днях подряд система предлагает лёгкий день (`intensive_model`: 1 день off — для accelerated обязателен) |
| Критерий завершения | Режим-2-контракт + 1 deep-блок; беглость/ИР — по недельному балансу |
| Перенос на завтра | как Режим 2 + артефакт deep-блока в «Мои артефакты»; письмо получает резюме S14-класса после (не во время) |

## Общие правила трёх режимов

1. **Выбор режима** — владение Profile (S20, настройка «дневной ритм» уже существует в замороженном дизайне: 15/30/60); день можно понизить одним тапом без вины; Recovery-механика (S6) остаётся отдельным входом после перерыва и не смешивается с «Минимумом».
2. **Система собирает состав дня** из блоков по узкому месту и недельному балансу — ученица не выбирает блоки вручную [доктрина A].
3. **Новые единицы считаются по таксономии** (слово/коллокация/chunk/фразовый — отдельные счётчики; конструкция — недельная, не дневная; произносительная черта — не «единица», а нить).
4. **Ничто из режимов не создаёт свидетельств** сверх фактических событий; process-метрики (минуты) — не критерий обучения; честные часы остаются единственным публичным счётчиком времени.
5. **Маркетинговая связка** [F]: «интенсив» продаётся как Режим 2-по-умолчанию с доступным Режимом 3; Режим 1 в витрине называется поддерживающим, не интенсивным.
