## Сводка ADR-статуса (коррекция v1.1 — противоречие снято)

Один ADR покрывает связку: **«Композитный день: день = режим × набор блоков; S5 — блок, не день; Daily Engine получает композитор и недельный балансировщик»**. Порядок зафиксирован: **(1) Draft ADR создаётся СЕЙЧАС** — документирует направление-кандидат (статус Draft, по конвенции governance не управляет реализацией); **(2) утверждение/заморозка ADR и широкая реализация — ТОЛЬКО после позитивного сигнала Этапа 0** и решения владельца; **(3) дорогое контент-производство (конвейер модулей) остаётся за воротами Этапа 0**. Формулировки «принять ADR сейчас» из v1 отозваны.
