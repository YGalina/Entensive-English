# Prompt

Design the complete Information Architecture from the frozen Constitution and approved Experience/UX Architecture.

Define every top-level, hidden, global, persistent, transient, authoritative, and projected object; hierarchy; ownership; relationships; entry points; exits; resume routes; protocol reachability; platform allocation; protected holdout projections; drafts, artifacts, evidence, events, reminders, search, library, and AI objects.

Rules:

- exactly one authoritative owner per state;
- navigation projects runtime state and never owns curriculum/protocol truth;
- persistence and authority are separate properties;
- holdout protection applies to all controlled retrieval paths;
- uncontrolled exposure is contamination evidence, not preventable filtering;
- maturity tags must match the Product Constitution.

Produce a complete IA tree. No layouts or visual design.
