# Prompt

Review the complete approved UX architecture before visual design: Product Constitution, Experience Architecture, UX Architecture, Information Architecture, User Journeys, Interaction Architecture, and Screen Specifications.

Assume prior findings are resolved. Do not redesign or reopen frozen decisions.

Review only cross-document consistency, navigation, discoverability, habit formation, learning psychology, cognitive load, interaction/state conflicts, edge cases, missing journeys, platform ownership, maturity mismatches, and ambiguity that would confuse visual designers.

Output Critical, Major, and Minor findings. For each: problem, why it matters, and minimal correction. Do not discuss aesthetics.
