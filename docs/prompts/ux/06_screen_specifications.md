# Prompt

Using the frozen Constitution and approved Experience, UX, IA, Journey, and Interaction documents, produce complete screen specifications.

For every approved screen specify purpose, maturity, platform default/override, entry, exit, required data, components, semantic priority, states, drafts, submit acknowledgment, completion contract, edge cases, loading, offline/storage failure, errors, AI behavior, voice lifecycle, analytics/events, privacy, and accessibility requirements.

Distinguish safe exit from curriculum/protocol completion; written from spoken evidence; partial data rescue from canonical final export; and process facts from capability claims. Planned surfaces must not be represented as implemented.

Do not produce visual design.
