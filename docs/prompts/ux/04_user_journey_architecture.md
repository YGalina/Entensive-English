# Prompt

Design all approved user journeys over time without drawing screens.

Include onboarding and profile outcome, pretest, first session/week, 14-session plus 14-day protocol, trained assessment, new context, holdout, explicit finalization, repeated read-only export, returning learner, interruption/resume, missed day/recovery, AI summary and structured dialogue, library launch, shadowing, community, milestone, reminders, inactivity, data-integrity failure, waitlist/not-eligible outcomes, long-term progression, and approved commercial boundaries.

For each journey define goal, entry state, steps, decisions, evidence/modalities, failures, safe exit, recovery, success condition, and destination. Do not introduce unratified subscription, data-retention, or progression rules.
