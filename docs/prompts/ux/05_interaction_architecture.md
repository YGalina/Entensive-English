# Prompt

Design interaction behavior from approved UX/IA/Journeys without visual styling.

Define interaction and feedback rules, scaffolded retrieval versus silent free production, drafts versus accepted immutable evidence, explicit submit/finalize semantics, safe exit, retry, undo, loading, offline/storage/sync states, empty/error states, AI availability, voice lifecycle, typing, animations/microinteractions, notifications, reward timing, Back/Close semantics, recovery, assessment integrity, and transition rules.

Do not turn assessment into practice. Do not infer psychological states from behavior. Only implemented task parameters may drive current adaptation; future axes remain planned.
