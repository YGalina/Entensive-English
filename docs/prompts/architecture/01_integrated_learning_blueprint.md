# Prompt

Act as Chief Curriculum Architect. Design the educational architecture that serves as the source of truth for Intensive English. Do not design UI, navigation, implementation tickets, or lesson content.

Read all research, methodology, curriculum, learning-experience, product-system, UX, competitor, exercise, learning-object, roadmap, and founder-decision materials. Create a source inventory first.

Answer: what exactly does the learner learn, in what order, why, how, how is it assessed, and how does it transfer?

Include:

- learning philosophy;
- competence architecture;
- progression based on learner capability changes;
- curriculum map across all skills;
- dependency graph;
- micro/daily/weekly/monthly/long-term cycles;
- content selection blueprint;
- receptive-to-productive transfer;
- diagnostic, formative, retention, transfer, and proficiency assessment;
- adaptation for uneven skills, time, energy, interests, and goals;
- post-B2 language lifestyle.

For every major claim label its status: evidence-backed, strong program precedent, product hypothesis, founder vision, or open research question. Never present implementation convenience as learning evidence.
