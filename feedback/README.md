# Обратная связь по UX — сбор перед волной правок

Здесь собираем аудиты продукта от нескольких ИИ (и людей), потом сводим и запускаем правки одной волной.

## Как собирать

1. Каждому ИИ даём **один и тот же промпт** — [`_prompt_ux-audit.md`](_prompt_ux-audit.md). Так ответы сравнимы.
2. Ответ сохраняем файлом `ГГГГ-ММ-ДД_<модель>_ux-audit.md` в эту папку.
3. Если ИИ не видит живой продукт — дать ему скриншоты ключевых экранов
   (Сегодня, сессия 4 фаз, вечерний круг, Библиотека, Словарь, онбординг)
   или `13_app_logic.md` как описание.
4. Решения Галины по ходу — дописывать в конец соответствующего файла
   в раздел «Решения», чтобы не потерять.
