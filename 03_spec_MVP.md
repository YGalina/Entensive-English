# Intensive English — Спецификация MVP

> Дата: 2026-06-29 · Версия: 0.1 (MVP-план)
> База: [01_research_method.md](01_research_method.md) · [02_concept.md](02_concept.md)
> Источник решений: Discovery Interview с Галиной.

---

## Executive Summary

Веб-приложение для интенсивного изучения английского по методу Петрусинского. **MVP = индивидуальный режим** (self-paced): человек заливает большой массив лексики через флеш-словарь, прокачивает понимание через shadowing по видео и скорочтение, всё с переводом и интервальным повторением. Контент подстраивается под профессию и интересы. Атмосфера мягкая, снимающая барьеры. Запуск на вебе, затем Telegram Mini App из той же кодовой базы.

---

## Проблема

Классическое изучение языка медленное и пугающее. У самой Галины (B1) типичные боли: слова не запоминаются, времена не применяются в речи, при чтении не хватает словаря, есть остаточный страх говорить. Метод Петрусинского бьёт ровно сюда: массивный ввод + многоканальность + снятие барьеров → быстрый результат.

---

## Критерии успеха (MVP)

1. Галина проходит полный цикл уровней 2–4 на себе и субъективно фиксирует рост словаря и скорости чтения.
2. Цикл «карточка → узнавание → shadowing» работает на реальном частотном словаре (3000+ слов) и реальных видео с YouTube.
3. Регистрация и прогресс сохраняются; статистика видна.
4. Архитектура готова к масштабированию (старт ~20 пользователей → сотни тысяч без переписывания).
5. Соответствие законодательству РФ по авторизации и хранению данных (см. раздел «Юридические ограничения»).

---

## Персоны

- **Галина (основной пользователь MVP)** — B1, мотивирована, готова на интенсив 5+ ч/день. Хочет разговор и расширение словаря.
- **Взрослый-профессионал** — учит под свой контекст (врач, инженер, саморазвитие).
- **Подросток** — общий и экзаменационный трек (позже).

---

## Пользовательский путь (MVP, индивидуальный режим)

1. **Вход** → регистрация (регион-зависимая, см. ниже) → короткий онбординг: цель, интересы/профессия, стартовый уровень.
2. **Уровень 1 «Готовность»** → экран настройки сессии: цель на сегодня, музыка (опц.), мягкая поддерживающая формула. Снимаем барьер.
3. **Уровень 2 «Узнавание»**:
   - **Флеш-словарь** — карточки `слово + перевод + транскрипция + готовая озвучка`. Режим быстрого предъявления (0,1–1 сек) и обычный.
   - **Скорочтение** — текст большими массивами, таймер, перевод слова по тапу.
4. **Уровень 3 «Воспроизведение»** → интервальное повторение (SRS): система показывает слова к повтору; узнавание «всплывает» за 2–3 повтора.
5. **Уровень 4 «Применение»** → **Shadowing-плеер**: видео с YouTube + субтитры + перевод, повтор за диктором.
6. **Прогресс** → статистика: слова усвоено, скорость чтения, стрик, рейтинг.

> Уровень 5 «Творчество» и диалоги/тренажёр времён — в v2 (см. «Вне MVP»).

## Функциональные требования

### Must Have (P0) — ядро MVP
- **Авторизация (регион-зависимая)** с соблюдением 199-ФЗ.
- **Профиль и онбординг**: цель, интересы/профессия, уровень.
- **Флеш-словарь**: импорт частотного списка (топ-3000–5000) с переводом и озвучкой; карточки; быстрый и обычный режим предъявления.
- **SRS-повторения**: алгоритм интервального повторения (FSRS/SM-2), состояние карточек на пользователя.
- **Скорочтение**: тексты, таймер, перевод по тапу, замер скорости.
- **Shadowing-плеер**: встраивание YouTube, субтитры + перевод, контроль темпа/повтора.
- **Контекст-паки**: выбор профессии/интереса → подбор лексики и видео (частотная база + генерация Gemini поверх).
- **Прогресс и статистика**: усвоенные слова, скорость чтения, стрик.
- **Двуязычный интерфейс** RU/EN.
- **Freemium-гейт**: часть функций бесплатна, остальное платно (граница уточняется скиллами pricing/offers).
- **Платежи (две контуры)**: РФ (ЮKassa / Telegram Payments / СБП) + мир (Stripe / Paddle).

### Should Have (P1) — сразу после MVP
- Telegram Mini App (та же кодовая база).
- Диалоговый конструктор + тренажёр времён в речи.
- Импорт слов из учебника Starlight.
- Расширенная геймификация (лиги, достижения).

### Nice to Have (P2) — позже
- Групповой режим (тренинги до 20 чел): синхронный поток, общий чат, парные диалоги, рейтинг.
- Доска Miro на уровне «Творчество».
- Говорение с оценкой произношения.
- Гарантийные программы (до 6 мес.).

## Техническая архитектура (предложение)

> Стек выбран под: быстрый старт, веб → Telegram Mini App из одной базы, горизонтальное масштабирование, соответствие закону РФ.

### Frontend
- **Next.js (React) + TypeScript + Tailwind CSS.** Один код → веб-приложение и Telegram Mini App (через Telegram WebApp SDK).
- Дизайн-система проверяется скиллом `ui-ux-pro-max` + design-критика.

### Backend
- **Next.js API routes** на старте (моно-репо, быстро). При росте — выделение тяжёлых сервисов (контент, SRS) в отдельные.
- **PostgreSQL** — основная БД (пользователи, карточки, прогресс, контент-паки).
- **SRS-движок** — FSRS (современнее SM-2), состояние карточек по пользователю.

### Интеграции
- **YouTube IFrame API** — shadowing и видео (видео не храним, только ссылки + тайминги субтитров).
- **Gemini API** — генерация недостающего: подборки под профессию, упражнения, объяснения.
- **Платежи**: ЮKassa/СБП/Telegram Payments (РФ) + Stripe/Paddle (мир), выбор по региону пользователя.
- **Озвучка**: берём готовую из частотных баз/словарей; **TTS в MVP не нужен** (решим точечно для слов без аудио).

### Хостинг (с учётом закона, см. ниже)
- **Данные граждан РФ — на серверах в РФ** (Yandex Cloud / VK Cloud / Selectel) — требование 152-ФЗ.
- Международный контур — глобальный провайдер / CDN.
- Возможна гео-сегментация хранения. Финал — после юридической проверки.

### Модель данных (ключевые сущности)
- `User` (регион, язык, цель, интересы/профессия, уровень, тариф).
- `Word` (англ., перевод, транскрипция, аудио-URL, частотный ранг, теги тем).
- `CardState` (user × word: статус SRS, следующая дата повтора).
- `ContextPack` (профессия/интерес → наборы слов и видео).
- `Text` (для скорочтения: контент, уровень, перевод-слой).
- `VideoItem` (YouTube ID, субтитры, перевод, тайминги).
- `Progress` (слова, скорость чтения, стрик, события).
- `Payment`/`Subscription` (контур, статус).

## ⚖️ Юридические ограничения (Россия) — критично

> Учтено по требованию заказчика. Перед запуском — проверка профильным юристом.

1. **Авторизация (199-ФЗ, штрафы для юрлиц 500–700 тыс. ₽ с 01.07.2026).**
   Для пользователей из РФ **запрещены** Google ID и Apple ID. Разрешено: **номер телефона (SMS), Госуслуги (ЕСИА), VK ID, Yandex ID, ЕБС, собственная email-авторизация.**
   → Решение: **регион-зависимый вход.** РФ: телефон + VK ID + Yandex ID + email. Мир: Google/Apple/email. Google/Apple не показываем РФ-пользователям.
   ⚠️ Статус Telegram-авторизации как «иностранного сервиса» — уточнить у юриста; для РФ-контура опираться на телефон/VK ID/Yandex ID.
2. **Хранение персональных данных граждан РФ — на серверах в РФ** (152-ФЗ). → Российский хостинг для РФ-данных.
3. **Домены .ru/.рф** — с 01.09.2026 идентификация через Госуслуги; возможны ограничения на иностранные сертификаты. → Рассмотреть нейтральный домен (.com) для международного контура + .ru при необходимости.
4. **Согласие на обработку ПДн, политика конфиденциальности, маркировка** — стандартный комплект.

## Нефункциональные требования
- **Масштаб**: старт ~20 пользователей; архитектура без переписывания до сотен тысяч (горизонтальное масштабирование, кэш контента, CDN).
- **Производительность**: карточки и предъявление — мгновенные; видео — стрим с YouTube.
- **Доступность**: веб (desktop + mobile), затем Telegram Mini App.
- **Тон/UX**: мягкая поддерживающая среда, снятие барьеров; копирайт по Норе Галь и «Пиши, сокращай» (скилл `copywriting`).

## Вне MVP (явно не делаем сейчас)
- Групповой режим и синхронные тренинги.
- Доска Miro.
- Диалоговый конструктор и тренажёр времён (P1, сразу после ядра).
- Генерация аудио (TTS).
- Гарантийные программы.

## Открытые вопросы для реализации
- Граница free→paid и ценообразование (скиллы `pricing`, `offers`, `lead-magnets`).
- Конкретный частотный список и база озвучки/переводов (лицензии).
- Выбор хостинга РФ-контура и схема гео-хранения данных.
- Юридическая проверка авторизации (в т.ч. Telegram) и оферты.
- Проверка концепции скиллом Product/UI-UX дизайна перед версткой.

## Поправки v0.2 (2026-06-29, по уточнениям Галины)

1. **Многоязычность по родному языку (L1).** Учим **только английский**; родной язык ученика выбирается (RU, AR, DE, FR, ES, IT, …). Переводы и интерфейс — под выбранный L1; для AR/FA — RTL. Модель данных слова: `en`, `ipa`, `def` (англ. толкование, универсальный фолбэк) + `tr` по кодам L1. Детали — [05_method_to_mechanics.md §7](05_method_to_mechanics.md).
2. **Машинопись/скоропечатание — модуль метода** (моторный канал, по Шестову), в дополнение к скорочтению. Обе — фазы/модули внутри блока, на той же пачке. См. [05 §6](05_method_to_mechanics.md). ⚠️ Ждём материалы Шестова от Галины для проработки раскладки и ритма.
3. **Темы (паки):** частотный костяк + строение организма, здоровье, дом и быт, эмоции, работа, дизайн-мышление, еда, путешествия/город, деньги, технологии, общение, природа; профтреки (медицина/инженерия/IT). Расширяемо.
4. **Онбординг** собирает: родной язык (L1) → цель → темы (мультивыбор) → уровень.
